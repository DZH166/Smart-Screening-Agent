# 素材提取（demo内测）

这是给员工试用操作界面的演示，尚未接入真实素材处理。

## 在员工网站打开

部署到员工网站后，先用原来的访问码登录，点击首页的“素材提取（demo内测）”即可。入口在新窗口打开，原来的图片编号页面继续保留。

直接入口为当前网站的 `/material-demo/`，无需另开端口或安装软件。页面和示例图片只对已登录员工开放；返回“图片编号”会打开 `/`，“管理员”会打开 `/admin`，仍需管理员登录。演示页不会读取或修改管理员设置。

## 在本机单独演示

需要 Python 3.10 或以上，无需安装其他依赖。在项目目录运行：

```powershell
python tools/material_demo_server.py
```

用浏览器打开 <http://127.0.0.1:8870/>。如端口已被占用，可在命令后加 `--port 8871`。关闭演示时，在启动窗口按 `Ctrl+C`。

## 可以体验什么

- 选择图片并预览，或直接查看内置示例。
- 点击“用示例体验提取”，按“下一步”查看三个演示步骤，再检查和下载内置素材；不会显示虚构的真实进度。
- 放大对照原图位置、选择、移除、撤销，以及下载单张 PNG 或示例 ZIP。
- 在“局部修正”中移动或调整框选范围、标记/擦除水印，并保存演示方案；不执行真实重做，下载仍是原始内置示例。
- 云端页面的顶部入口通向真实图片编号和管理员页面；本机 8870 的独立原型保留编号和统一管理分区的界面示意。

## 请先了解

- 这是界面内测，不是已接入 AI 的正式素材提取功能，不改变现有图片编号的处理规则。
- 选择的图片只在当前浏览器中预览，不会上传到本地服务或云服务器。
- 处理过程和素材结果是内置演示，不会对上传图片进行真实识别、去水印或抠图。
- 下载的是内置合成示例，不是所选图片的真实处理结果。
- 不调用任何 AI 服务，不读取现有 Key、员工文件或生产任务，不产生 AI 费用。
- 关闭或刷新后，当前演示操作不保留；所选图片没有上传到网站。

## 本轮核对

实际浏览器检查了本机选图预览、三个示例步骤、原图对照、框选移动/缩放、画笔/擦除、保存方案、移除/撤销、功能区切换，以及单图和 ZIP 下载。ZIP 解包为六张 320×320 的 RGBA PNG，每张均含透明和不透明像素；这些只证明演示交互和下载可用，不证明任何 AI 处理效果。

此前在1366×768、1920×1080及600×800下检查了本机原型布局。截图和下载检查仅留本机。这些演示检查不证明真实 AI 处理效果，也不代替员工对新素材功能的后续验收。
