怎么填写与常见问题
  1. 在 DeepSeek 控制台创建 API Key，每行粘贴一个后点“添加 Key”，再勾选“启用 DeepSeek”并保存。
  2. 员工共用这些 Key，不在各自电脑配置；增加 Key 不会增加官方账户额度。
  3. 显示“待验证”表示还没有成功调用记录；冷却中的 Key 会显示剩余时间，到期自动恢复。
  4. 更换 Key 时先停用旧 Key，再添加新的，确认可用后再删除旧 Key。
  5. 保存成功只代表配置已写入，不代表接口可用；真实效果仍需实际调用确认。
