怎么填写与常见问题
  1. 打开火山方舟控制台创建 API Key。这里使用方舟 API Key，不填写云账号的 AK/SK，也不填写 DeepSeek Key。
  2. 开通所需图片模型，复制 Model ID 或自己的推理接入点 ID，粘贴到上方。Key 需要有该模型的使用权限。
  3. 保存后输入框会清空 Key，这是正常保护。想更换 Key，重新粘贴并保存；删除配置会同时关闭验证开关。
  4. 提示“其他页面已更新”时，先刷新再修改；保存结果不明确时，也先刷新核对。
  5. 保存设置不会调用图片服务。启用后，员工开始提取时才会把所选图片交给火山方舟处理；不确定的结果会提示员工确认。
