# 安装包与内网 AI 网关部署

本轮交付状态（2026-10-20）：v1.10.1便携版已实际验证。自动审批拒绝安装Inno编译器，尚未生成或验收v1.10.1安装包；下文Setup路径是构建模板，不是已发布附件，旧版67.7MB测量不能当作新版实测。当前员工直接访问共享网页即可共用主机Key，无需安装或网关。审查发现全库查找客户端的网关endpoint参数不兼容且仍固定官方地址，可选网关不作为已验收的全库方案，本轮不启用。见[同步上线记录](deployment-v1.10.1-verification.md)。

本文说明如何把「智筛 Agent · HSD 图号助手」做成可分发安装包，并让多台电脑共用同一个 DeepSeek 密钥。

## 1. 两种角色

| 角色 | 装几台 | 需要做什么 |
| --- | --- | --- |
| 员工客户端 | 每台电脑一份 | 双击 Setup 安装，之后正常使用；**不填 DeepSeek Key** |
| 内网网关主机 | 一台，长期开着 | 存唯一一份 DeepSeek Key，员工机器的 AI 复核请求都转到这台 |

选网关方式的原因：密钥用 Windows DPAPI 按「当前用户 + 本机」加密保存，**密文复制到另一台电脑解不开**，所以"配好一份配置发给所有人"做不到。网关方式让密钥只存在一台机器上，客户端只拿一个内网令牌。

## 2. 制作安装包（开发机）

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" .\installer\HSD图号助手.iss
```

产物：

- `dist\v1.11.0\HSD图号助手\`：绿色版目录（可直接拷走使用）
- `交付\HSD图号助手-Setup-1.11.0.exe`：安装包（实测约 67.9 MB）

`build.ps1` 用 Windows PowerShell 5.1 直接执行会因为 UTF-8 无 BOM 读成 GBK 而报错，上面的 `powershell -NoProfile -ExecutionPolicy Bypass -File` 形式可用；若系统执行策略禁止脚本，先在该窗口执行 `Set-ExecutionPolicy -Scope Process Bypass -Force`。

## 3. 分发给员工

把 Setup 放到公司内网共享盘，员工双击安装即可：

- 默认**按当前用户安装**，不需要管理员权限，装到 `%LOCALAPPDATA%\Programs\HSD图号助手`
- 自动创建开始菜单项；可勾选桌面快捷方式
- 控制面板「应用和功能」里可正常卸载，卸载不会删除业务数据

IT 批量部署可用静默参数：

```powershell
\\共享盘\HSD图号助手-Setup-1.11.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

未做代码签名，员工首次运行会看到 Windows SmartScreen 的"Windows 已保护你的电脑"。点「更多信息 → 仍要运行」即可；这一步每次安装包版本更新后都会出现。要彻底消除需要购买代码签名证书，本次未做。

## 4. 架设内网网关（一台主机）

1. 在这台机器上装好安装包，安装时勾选「本机作为内网 AI 网关，开机自动运行」。
2. 手动启动一次以便填写密钥：

   ```powershell
   & "$env:LOCALAPPDATA\Programs\HSD图号助手\HSD图号助手.exe" --gateway --gateway-bind 192.168.0.160 --port 8899
   ```

   `--gateway-bind` 必须是本机的内网 IPv4；省略时会自动挑一个内网地址，多网卡机器建议显式指定。

3. 浏览器会打开 `http://192.168.0.160:8899/`，页面显示监听地址、请求统计和客户端的 `gateway.json` 内容。在页面下方填入 DeepSeek API Key 并保存——密钥用 DPAPI 存在这台机器上，页面和接口都不会回显它。

4. 放开防火墙（管理员 PowerShell，路径按实际安装位置替换）：

   ```powershell
   New-NetFirewallRule -DisplayName 'HSD内网网关-8899' -Direction Inbound -Action Allow -Protocol TCP -LocalAddress '192.168.0.160/32' -LocalPort 8899 -RemoteAddress '192.168.0.0/24' -Profile Any -Program "$env:LOCALAPPDATA\Programs\HSD图号助手\HSD图号助手.exe"
   ```

   只开放给指定的主机地址、端口和来源子网，不要把端口映射到公网。

5. 把网关页面上的 `gateway.json` 内容保存成文件，**放在每台员工电脑的安装目录**：

   ```text
   %LOCALAPPDATA%\Programs\HSD图号助手\gateway.json
   ```

   更省事的做法：把这个 `gateway.json` 和 Setup 放在同一个共享目录，安装器会自动复制到程序目录。批量重装时不用逐台再放。

## 5. 客户端如何选中网关

程序按以下顺序决定"用谁的凭据"：

1. **本机已保存的 Key**（含 DPAPI 解密成功的旧配置）→ 直连 DeepSeek 官方接口
2. **环境变量** `DEEPSEEK_API_KEY` → 直连官方接口
3. **网关** `gateway.json` / 环境变量 `HSD_AI_GATEWAY` + `HSD_AI_GATEWAY_TOKEN` → 走内网网关

因此：员工机器上**不要**保存任何 Key，就会自动走网关。网关装好后，本机设置页显示"已启用/已配置"但看不到密钥来源细节；员工端本来也改不了设置。

环境变量覆盖文件，便于 IT 临时切换：

```powershell
[Environment]::SetEnvironmentVariable('HSD_AI_GATEWAY','http://192.168.0.160:8899/v1/chat/completions','Machine')
[Environment]::SetEnvironmentVariable('HSD_AI_GATEWAY_TOKEN','网关页面上的令牌','Machine')
```

网关地址只接受 `https://`，或指向内网/回环地址的 `http://`；带账号密码、查询串或公网明文 http 的地址会被忽略。

## 6. 排查

| 现象 | 处理 |
| --- | --- |
| 员工端提示"AI复核未启用" | 检查安装目录是否有 `gateway.json`；确认这台机器没有保存过本机 Key |
| 员工端提示"网关访问令牌无效" | `gateway.json` 的 `token` 与网关页面上显示的不一致，重新取一次 |
| 员工端提示"上游接口暂不可达" | 网关机器能不能访问 `api.deepseek.com`；网关进程是否在运行 |
| 网关页面打不开 | 只在主机本机可访问；确认 `--gateway-bind` 的地址和端口，以及防火墙规则 |
| 网关页面显示"未保存" | 在页面下方填 Key 保存；或检查该机器是否换了 Windows 账户（DPAPI 按用户加密） |
| 员工机器上 AI 仍然直连 | 该机器存过本机 Key，在 AI 设置里清除后再保存 |

网关进程日志：`%LOCALAPPDATA%\HSD图片编号工具-网关\运行日志.log`，只记录时间、级别和错误类型，不记录密钥、请求正文或图片。

## 7. 已做的安全约束

- 网关只监听一个明确的内网 IPv4，拒绝公网、回环、`0.0.0.0`
- 客户端请求必须带 `Authorization: Bearer <令牌>`，令牌随机生成、按安装目录保存
- 请求体上限 32 MiB，响应上限 1 MiB，上游重定向一律拒绝
- 状态页和密钥填写页**只允许主机自己访问**，并且校验来源；页面不回显密钥
- 原始 XLSX、ZIP、AI 文件和本机路径仍然不发送给 DeepSeek；只有符合复核条件的图片预览会经网关转发

## 8. 本次未做的部分

- 没有代码签名证书，SmartScreen 首次拦截仍需手动放行

- 网关没有做多用户账号、配额或费用上限；费用统计仍在每台客户端各自记录，不汇总
