# 丝带设计的模型调用

当前管理员页在「Key账本→丝带设计」沿用已启用的DeepSeek＋Seedream；OpenAI适配保留，但当前页不开放切换，本轮也不对其账号连通作承诺。员工不填写密钥；保存设置不发模型请求，不等于接口或画质已验证。

| 路线 | 理解文字要求 | 生成底图、编辑图片 | 配置来源 |
| --- | --- | --- | --- |
| OpenAI | Responses 结构化编辑计划 | Images 生成与编辑接口 | 丝带独立 Key、语言模型 ID、图片模型 ID |
| DeepSeek＋Seedream | DeepSeek JSON 编辑计划 | 火山方舟 Seedream 图片接口 | 沿用已启用的 DeepSeek 账本与火山方舟设置 |

首稿由原素材排版，不重画整幅图片，也不占两次精修额度。文字修改先形成受控计划，再执行参数调整或请求图片编辑。背景、图案分别修改后重新排版；整幅编辑会记录其图层能力变化。模型无法满足时明确失败，不回退演示图。

## 当前工作流分工

| 环节 | 负责方 | 边界 |
| --- | --- | --- |
| 按要求生成底图 | Seedream | 员工可输入要求，留空随机；不发送图库案例 |
| 首稿和14种排版 | 程序 | 用原图案合成，不重新画人物/文字 |
| 理解文字精修 | DeepSeek | 读取文字、所选图案名称/顺序、当前参数与支持能力；不看图片，不猜不明确的视觉对象 |
| 缩放、间距、旋转、偏移、纯色 | 程序 | DeepSeek提出计划，服务端验证并执行真实变化 |
| 图案/底图内容修改 | Seedream | 仅提交指定对象，保留原图和派生关系，再按原尺寸合成 |
| 保存、两次额度、父回退、下载 | 服务端 | 模型不能改权限、编号、业务额度或历史版本 |

计划最多8项，统一预检查全部操作/参数/目标及待编辑图片。没有实际变化时澄清，不创建版本或扣次数；前一项正常、后一项明显尺寸不支持时，不先发第一张图片请求浪费调用。首次等待与恢复、修改图案与底图的阶段分别显示。

能力投影在`config.editing`及`version.editing`，后者按作品自己的已保存尺寸计算，不把新的全局规格套给旧作品；不可变snapshot不被读取接口改写。员工页面缺AI配置时仍可原素材首稿和仅应用真实新选择。`test+local/demo`明确标记的替身可继续演示；`test+hsd`禁止执行模型任务。

每个任务绑定提交时的路线和模型设置。后续设置发生变化时，不把旧任务切到新模型继续跑。超时或返回结果不明时不自动重发；失败不扣精修次数，但外部调用仍可能计费。DeepSeek 共用原 Key 池，包括全池限流冷却与用量记录。密钥加密保存在主机，普通接口、员工页面和日志不回显。

## 接口依据

- OpenAI [结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)：用 `text.format` 的 JSON Schema 生成编辑计划，服务端仍检查计划与权限。
- OpenAI [图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)：请求图片编辑并读取内联图片结果，不下载模型返回的任意外链。模型可用性与图片规格取决于管理员账号及所填模型。
- 火山方舟 [图片生成 API](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-api)：Seedream 5.0 Pro/Flash 支持 `background=transparent`，但只用于输入一张带透明通道的图片，并输出 PNG。普通底图生成不使用透明模式；不把 RGBA 格式本身当成成功去背景。
- DeepSeek [JSON输出](https://api-docs.deepseek.com/guides/json_mode/)与[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)：JSON请求提供格式指令和合理输出长度，本轮编辑规划明确`thinking: disabled`，不展示或保存隐藏思考。

DeepSeek及火山方舟协议于2026-10-30重新核对；OpenAI来源保留上轮2026-10-28适配依据。透明输出、尺寸、单图数量等再次检查，不通过保留旧版本。丝带提示词独立于素材提取，不用去水印/拆图提示词修改丝带设计。

## 当前验证边界

已用模拟接口验证请求格式、共享Key池、设置冲突、未知返回不重试、透明异常、低清/尺寸错配、全部输入预检及密钥不泄露。2026-11-02同一线上源码以自制透明小花完成4次真实外呼、两次精修、回退和三版本下载核对。模型增加轻微纹理，底图也有额外图形；完整观察及业务验证边界见[模型工作流回执](ribbon-model-workflow-verification.md)，不把连通成功当印刷或文字配色保真证明。

原默认演示配置保留，线上正式配置为300DPI、RGB、11811×520px。模型输出像素多不等于恢复原图细节。图片编辑限制不同，不满足条件时修改独立图案/底图，不缩小重画后放大冒充原母版。

Seedream整幅编辑只接受原宽高合法的画布，像素921600–4624220、比例不超16:1；当前11811×520不符合，故不给出整幅编辑承诺。底图请求和验证原生2048×2048；独立编辑按源比例计算约4MP合法画布并精确验证返回尺寸/透明，不能接受512像素假返回后虚放为高清。这些工程条件也不等于印刷、文字保真或无缝效果验收。
