# 素材提取：效果验证计划（尚未执行）

更新：2026-10-22。本文记录已确认范围、现有方案缺口及验证方法；不代表模型效果已通过。

当前仅有交互Demo及配置准备。用户已取消fal，改用火山引擎「火山方舟」；先保存方舟API Key和图片模型ID，再进行真实接口验证。旧fal适配器和下表原实现仅作历史参考，不再作为当前接入方案。在真实效果和员工任务流程验收前，不开放正式员工提取，不把合成示例下载称为真实提取。

## 已确认的第一版范围

- 一次选择或拖入多张 PNG、JPG、WebP，按原图查看结果。
- 一个完整设计包含所属人物、文字、装饰和内部底板，只去掉设计外部背景。
- 清理水印；尝试修补遮挡、模糊，及实物照片中的倾斜、弯曲、褶皱。尽量保留原文字和配色，不主动换色、改字。
- 每个完整设计输出一张透明 PNG，保持比例，目标长边 4096 像素；实际印花尺寸由生产软件决定。像素尺寸不能代替真实细节质量。
- 可靠项可直接下载，只处理系统标出的疑难项。修补不确定的位置可见，员工确认后仍可带提示下载。
- 漏提取或拆分错误时重新框选完整设计，仅重做该范围；其他问题可标记位置、选择修改要求并补充文字。
- 单项失败自动重试一次，仍失败交员工处理；保留其他成功项。没有费用上限，也不沿用源项目的每图预算暂停。
- 整合现有员工与管理员权限、任务隔离、三天暂存及结果下载，不使用 OSS，不改变现有图号助手规则。

## 现有方案与能力缺口

参考实现为本机原素材工厂 `server/processor.ts`、`server/imaging.ts` 与 `server/providers/`，不是当前网站的真实生产能力。

| 环节 | 原方案已有实现 | 本次尚需补齐或实测 |
| --- | --- | --- |
| 设计盘点 | DeepSeek 全图加四个重叠分块，返回粗框、分组说明、水印区域 | 密集小图漏检、分块截断、相邻完整设计的误合并；模型框不是像素边界 |
| 完整设计分割 | fal SAM 3 像素蒙版，矩形设计保留内部背景 | 脱离主体的文字/装饰是否丢失；相邻设计是否粘连；二值化边缘是否有锯齿 |
| 水印修复 | 分割水印笔画，在前景交集内局部修复，区域外保留解码后的像素 | 文字与水印误判、五官/正文被改、大片遮挡；没有干净参照时只能判断可接受性 |
| 展平与修补 | 无实物展平流程 | 杯面、衣服褶皱、透视变形及被遮图案需新增并对照验证，不能靠改提示词宣称实现 |
| 4096 输出 | 原尺寸裁图及 PNG 合成 | 没有细节增强模块；需要分别记录原生尺寸、增强方式和实际输出尺寸 |
| 自动判定 | 全部结果标为待检查 | 没有可靠项直接下载的验证门槛；不能把无警告或模型自报高分直接当可靠 |
| 交互 | 单图、框选、合并、画笔水印蒙版 | 多图、问题类型和补充文字，以及仅重做目标项仍需整合 |
| 失败恢复 | 留住已有结果、队列取消及防重复提交 | 需实现最多一次自动重试；请求是否已执行不明时先跟踪原请求，不能盲目重复提交 |
| 云端运行 | 原应用面向办公室局域网、单任务、24 小时暂存 | 不能照搬其本机管理员/存储/上传限制；必须使用本项目云权限、三天清理和资源隔离 |

原流程对五个视图和多个素材串行调用。并发只在测量供应商等待、服务器内存和限流后决定；不能把请求数少或视觉进度更快当质量提升。

## 当前验证方案：火山方舟直连

管理员保存方舟API Key与已开通的图片模型ID/接入点ID。保存/开关不进行模型调用；Key私有加密且不回显，不读取原fal文件，DeepSeek独立保留。官方[图片接口](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-api)使用API Key鉴权，具体能力和分辨率以实际开通模型为准，不把所有图片模型都视为支持透明分层或4096。

后续应以同一组冻结样图，分别验证方舟可用的图层拆分及图像编辑方案，观察完整设计是否被拆散、文字/颜色是否改变、透明边缘、修补与展平、原生分辨率及真实耗时。先确认模型支持与授权，再进行真实接口开发/对照。未确认的生成结果必须交人工；分层能力和PNG格式本身不等于生产质量合格。

不再调用fal对照或要求用户开通fal。旧文档及适配器的模拟测试只证明历史程序控制，不能证明当前方舟接入或素材效果已完成。不设置费用上限，不接OSS或新增对象存储；后续供应商图片发送范围及下载校验需要在真实调用前明确落实。

## 可独立判断的控制案例

控制案例优先由自有设计构造，有已知干净版本、文字及颜色。它们可验证程序保真和错误提示，但不能替代业务留出验证。

| 控制组 | 变化 | 必须检查的结果 |
| --- | --- | --- |
| 完整分组 | 人物加离散文字、花朵、耳环；旁边另有独立设计 | 同一设计不拆散，其他设计不粘入 |
| 内部底板 | 海报、旗帜、徽章加外部桌面/背景 | 内部底板保留，只移除外部背景 |
| 水印与正文 | 斜向重复水印跨脸/正文；设计本身有相似字体 | 水印残留、误删正文及修补失真分别记录 |
| 颜色 | 近似同图换色、小区域换色、灰白浅色边 | 有意义颜色不被“纠正”；亮暗背景均无明显边缘污染 |
| 内容 | 局部增减图案、小字替换、镜像、极近似邻图 | 不凭整体相似放过改字、丢配件或错误对应 |
| 几何 | 已知平面设计做透视、曲面、褶皱模拟 | 与干净参照对齐检查；不把仅旋转当复杂展平已通过 |
| 遮挡与截断 | 小面积遮挡、正文不可读、源图边缘截断 | 不确定部分必须标记，不把猜补称作真实恢复 |
| 尺寸与 alpha | 宽图、长条、小透明孔洞、半透明抗锯齿、透明原图 | 保比例、长边 4096、alpha 正确、无拉伸和白边；放大不等于高清 |
| 故障 | 坏图、无结果、错比例蒙版、限流、超时、取消 | 不冒充成功；一次有界重试；保留已有结果；停止后无新计费提交 |

## 私有人工标签和运行记录字段

标签在模型调用前冻结；人工验收看原图、必要的干净参照和匿名方案编号，不能只看模型自评。

| 记录 | 建议字段 |
| --- | --- |
| 输入清单 | 样本 ID、授权/来源、原图摘要、真实编码及尺寸、调试或留出组、分组版本 |
| 设计参考 | 稳定设计 ID、粗框/像素参考、必须保留文字和配件、内部底板、已知遮挡/截断、可评价范围 |
| 单次运行 | 方案与模型 ID、实现提交、参数/提示版本、开始结束时间、上游请求 ID、原请求/自动重试/人工重做、状态与失败原因 |
| 单设计验收 | 是否漏检/误拆/粘连/多余、文字、配色、完整性、边缘、水印、修补、展平、真实尺寸/alpha、发现的问题是否被系统标出 |
| 人工处置 | 未改直接可用、标为疑难、人工修正后可用、带已知问题确认下载、不可用；评审人及时间 |

真实图片上的不可见内容没有可验证真值，不能填“已准确恢复”。对无干净版本的文字或脸部修补，记录“员工认为可接受/不可接受”及可见问题即可。

## 汇总与上线判断

必须同时报告：

- 人工冻结的完整设计总数、正确完整输出数、漏检数、误拆/粘连数及多余输出数。
- 自动产生且未经人工修改可用数；人工改后可用、带问题接受和失败单列，不能混算。
- 系统直接放行中的实质问题数，以及全部实质问题中有多少已被系统标为疑难。发现不了问题却全部放行，不能称减少了人工审核。
- 原生尺寸与 4096 输出均验证；增强耗时与上游等待、排队、服务器处理、人工操作、整批耗时分别记录。
- 原请求、失败、重试、取消和人工重做均保留。没有费用预算，但费用未知时不能记录为零。

当前未定义用户签字认可的质量百分比门槛，不沿用源项目旧“90%”作为本次已确认承诺。先给出同输入对照结果，再按真实表现确定可靠类别和疑难条件。

独立留出尚不足、关键颜色/文字被改、源图覆盖无法验证或新流程仍只产生全部待检查项时，报告限制并继续内测，不以修改标签声称达到“只审核疑难”的目标。

正式上线还需独立检查：员工 A 不能取员工 B 的原图/结果；管理员 Key 不进入员工响应；CSRF 与版本冲突有效；停止等待后台收敛；处理中不清理；下载可重试；原图与此前成品保留；其他网站和原编号功能不受影响。
