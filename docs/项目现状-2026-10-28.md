## 2. 已经稳定在用的功能

- **图号助手**：导入 XLSX/ZIP → 自动查找与核验 → 疑难项人工确认 → 摘要导出；已有编号原样保留，只为成功匹配的缺号行生成 `HSD+四位`。
- **素材提取**：多图上传 → 整图清理 → 定位 → 逐设计 2K 提取 → 直接下载 / 精修 / 舍弃恢复；结果全部可下载但**不代表人工验收或画质合格**。
- **员工访问码**：管理员在「Key 账本 → 员工访问码」增删停用；只存带盐哈希；多码并存、按码不共享任务。
- **管理员区**：独立账号密码（只存 PBKDF2 哈希），可查看 DeepSeek 账本与火山方舟 Key（仅这两个接口允许明文，且需管理员会话）。
- **隔离**：员工看不到彼此任务；主机专属操作在云模式禁用。

## 4. 已知边界（不是待修 bug）

1. **升级会作废旧批次**：素材实现签名含版本号，升级后未完成批次不会续跑，需员工重新上传。部署前必须 `busy jobs: 0`。
2. **单 worker、不可扩容**：会话和任务归属在单进程内存里；加 worker/多实例会互相覆盖。慢只能靠减少并发批次。
3. **三天保留**：下载要及时；`acceptance/`、`tmp/` 不在自动清理范围。
4. **同 IP 不同端口不隔离浏览器 Cookie**：这是端口方案固有限制，后续如换独立域名才能解决。
5. **AI 需要管理员配置**：DeepSeek 与火山方舟 Key 由管理员在设置页保存；未配置时相关功能不可用，但本机流程/页面仍可打开。
6. **识别与画质不是保证**：定位、贴边过滤、精修都只降低失败率，不承诺任意图片一次成功或达到印刷级清晰度；员工仍需自测。

## 5. 本轮质量审核结论（摘要）

- 发现并修复 6 处：素材任务首存失败会永久卡在“处理中”、精修期间整批不可下载、失败批次源图状态不收敛导致无法一键重试、ZIP 目录区可造成内存爆炸、DNS rebinding 可读内网网关令牌、登录限流表可被未认证流量撑爆。
- 补 5 项运维能力：`/healthz` 存活探针、Gunicorn 访问日志、systemd 加固、健康检查定时器、配置与密钥备份脚本。
