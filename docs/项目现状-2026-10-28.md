## 2. 已经稳定在用的功能

- **丝带真实模型工作流**（v1.22.0）：底图可填写要求；DeepSeek只做文字规划，Seedream生成底图/编辑独立图案或底图，程序合成原尺寸母版。整幅长条直接重画不开放；无变化不扣次数。真实自制花联调已通过，模型轻微纹理/配色变化与额外底纹仍需业务实测，不是印刷质量验收。
- **图号助手**：导入 XLSX/ZIP → 自动查找与核验 → 疑难项人工确认 → 摘要导出；已有编号原样保留，只为成功匹配的缺号行生成 `HSD+四位`。
- **素材提取**：多图上传 → 整图清理 → 定位 → 逐设计 2K 提取 → 直接下载 / 精修 / 舍弃恢复；结果全部可下载但**不代表人工验收或画质合格**。
- **丝带设计**（v1.20.0 起，v1.26.0 升级）：同页第三入口，沿用员工登录与管理权限；首稿 + 最多两次成功精修、失败不扣、回退续期，指定版本下载。AI 已按本机 Key 账本启用（DeepSeek＋Seedream），丝带模型服务有独立页面 `/admin/ribbon`，与素材提取共用同一份配置；OpenAI 路线因服务器无法直连 `api.openai.com` 暂不提供。预览分「细节 / 整条」：细节看母版（`/api/ribbon/versions/{id}/view`），整条和缩略图看轻量预览。输出规格已按设计师要求定为 300 DPI、RGB、含出血总高 4.4 cm（上下各 0.3），长度方向不留出血，画布 100 cm（11811×520 px）。开发前请读[丝带助手功能与架构](丝带助手-功能与架构.md)。
- **员工访问码**：管理员在「Key 账本 → 员工访问码」增删停用；只存带盐哈希；多码并存、按码不共享任务。
- **管理员区**：独立账号密码（只存 PBKDF2 哈希），可查看 DeepSeek 账本与火山方舟 Key（仅这两个接口允许明文，且需管理员会话）。
- **隔离**：员工看不到彼此任务；主机专属操作在云模式禁用。

## 4. 已知边界（不是待修 bug）

1. **升级会作废旧批次**：素材实现签名含版本号，升级后未完成批次不会续跑，需员工重新上传。部署前必须 `busy jobs: 0`。
2. **单 worker、不可扩容**：会话和任务归属在单进程内存里；加 worker/多实例会互相覆盖。慢只能靠减少并发批次。
3. **50 小时保留**：下载要及时（比原来少一天）。`storage/tmp` 是服务的 `TMPDIR`，目录本身不能删，里面的历史验收残留可以人工清；`storage/acceptance` 不被运行时代码使用，2026-10-28 已人工清空一次，之后跑验收还会留新文件。
4. **数据卷 15 GiB**：循环镜像建在根盘上，扩卷等于用根盘换容量。2026-11-06 剩余 12.5 GB；健康告警线仍是剩余 < 1 GiB。
5. **同 IP 不同端口不隔离浏览器 Cookie**：这是端口方案固有限制，后续如换独立域名才能解决。
6. **AI 需要管理员配置**：DeepSeek 与火山方舟 Key 由管理员在设置页保存；未配置时相关功能不可用，但本机流程/页面仍可打开。
7. **识别与画质不是保证**：定位、贴边过滤、精修都只降低失败率，不承诺任意图片一次成功或达到印刷级清晰度；员工仍需自测。
