2026-10-22，最初基于主线 v1.13.4 的 `795e327`；交付前同步 v1.14.1 的 `ea6585e`，保留管理端三个侧栏入口，访问码入口位于“功能区”，分支为 `codex/admin-access-codes`。本次只开发、验证并推送分支；未合并主线、未切换正式网站、未创建正式版本或安装包。

## 员工和管理员怎么使用

1. 管理员登录，点击首页“功能区”中的“员工访问码”。
2. 填写新码和可选备注，点击“增加访问码”，看到成功提示后再告诉员工。先自行保存，添加后不再显示原码；备注不要填写访问码。
3. 员工在原登录页输入任意一个已启用的有效码，即可进入图号助手。格式要求随实例显示，云端默认至少16位，仍允许原先已明确设置的实例最短长度。
4. 新增码可以停用、启用和删除。停用/删除阻止之后用该码登录；已经登录的员工不会被强制退出。原有配置码继续使用，此页面不能修改它。
5. 提示其他页面修改过设置，或保存结果不明确时，先刷新核对，再操作。不同浏览器的任务仍各自隔离，同一个码不代表共用任务。

## 安全和保存边界

新增码仅保存带盐PBKDF2-SHA256校验值，私有路径为共享设置目录的`employee_access/access_codes.json`，不属于任务三天清理范围。Linux目录/文件权限0700/0600，拒绝符号链接、硬链接、外来所有者和异常权限；原子落盘、版本冲突、文件损坏/消失、盐变化和版本回退均检查。保存过程中注册表消失不能悄悄重建；提交后同步出错时要求刷新核对，不能假报未生效。

新码和原码在同一登录失败次数限制中验证。每次登录只执行一次昂贵派生，再恒时比较当前条目，避免访问码越多就重复执行大量派生。单工作进程规则保持；多进程共享同一设置目录不在支持范围。首次初始化会创建空注册表；停服期间丢失文件与首次部署不能仅靠文件缺失区分，需要管理员保管好私有设置目录，不提供外部备份恢复功能。

管理页面和资源需独立管理员认证，写入还验证精确来源、写入令牌与版本。员工码不授予管理员或主机权限；同码/异码浏览器的任务不可互读，云原浏览器换有效码重登仍只恢复本人同版本任务。本机模式无员工入口时不允许新增码。

没有调用真实DeepSeek/fal，没有修改线上访问码、Key或权限，没有使用10.12批次，没有改变匹配、编号、自动通过或导出判定。后续合并部署属于代码升级，原有任务仍不跨实现恢复，升级前应完成并下载。
