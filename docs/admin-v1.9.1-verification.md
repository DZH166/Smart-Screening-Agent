# v1.9.1 管理员页精简

## 范围

用户明确要求删除费用估算和实时调试界面，并让管理员页简洁清晰。本版将主界面收敛为 AI 开关与 API Key 管理，移除累计/每 Key 费用、请求统计、调试日志 DOM、渲染逻辑及两秒增量轮询。标签、启停、批量添加、删除确认和必要异常仍保留；发送范围、资格与加密说明折叠至“使用说明”。不改匹配/编号、DeepSeek 请求/资格、任务隔离或导出规则。

只读 GET /api/admin/keys 仅查询设置与池状态，不读取累计账本或调试缓冲。页面30秒读取状态，隐藏或离开停止；后台刷新不禁用编辑控件。检测到其他页面修改时保留原输入与确认框，显式刷新才重新载入。与写操作重叠的旧读取不覆盖新设置。后端保留累计账本及任务完整记录，删除界面不等于清除诊断证据。

实际 Windows EXE 最终 02 套管理员/员工验收通过：DPAPI 旧单 Key 迁移、批量 Key、改标签/启停/删除、400/403/409、新只读接口、双会话归属、合成员工上传/导出/ZIP 下载与原稿/WPS 字节核对。两个独立验收进程正常退出 code0，4 份完整私有导出记录保留；均使用隔离设置，未读取用户密钥、未调用真实接口。早先01套证据保留，不混为最终构建。

实际页面检查了1366×768与1920×1080：AI开关、输入框、添加按钮及测试Key行的常用操作可见；没有费用/调试面板和嵌套日志滚动。说明可展开，标签保存、Key启停及删除确认可操作。实际操作发现了AI开关切换后旧池状态短暂显示“AI已关闭”的矛盾，已清除过期状态并追加只读更新；重打包后关闭/重新启用复测通过，GET失败也不回滚已成功保存的开关。最终恢复默认窗口，截图保存在本机。

本版严格只有版本、server只读路由及admin三静态文件共5份生产输入变化；与已发布v1.9.0的33份实际源码清单比较，11个匹配/AI模块字节及源码/冻结实现签名完全未变。最终包绑定33份输入、1215个运行文件。不是通过修改匹配标签或放行条件精简页面，也不根据浏览器自动化等待时间宣称算法/界面提速。
