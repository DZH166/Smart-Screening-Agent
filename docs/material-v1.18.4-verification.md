# v1.18.4 验证记录

日期：2026-10-27

## 本次改动

用户反馈三点：

1. 部分结果仍带白色贴纸边，需要干净的透明个体图。
2. 六七个个体的密集拼图，产出的清晰度不够。
3. 素材对照弹窗切换素材时，会停留在上一张一会儿才显示下一张。

对应处理：

- 提示词重新明确：主体尽量占满画面、边缘锐利；不要白色底、不要白色贴纸边、不要白色或彩色外描边、不要光晕和投影；同时保留原文字、配色、内部底板。
- 单个设计占原图面积低于 4% 时，不再让模型在整图上辨认百像素级小图，改用该设计自己的放大局部参考图（外扩 12% 起、最多约 400 万像素，必要时再外扩到 30% 保留上下文）。仍然每个设计只发一次请求，没有新增自动精修。
- 对照弹窗先显示已缓存的 640px 缩略图，完整 PNG 解码完成后替换；切换素材不再停在上一张。

## 真实拼图回执（2026-10-27）

测试对象：早前上传的第二张真实拼图（960×827，54 个设计），走完整流程：整图清理 1 次 → DeepSeek 定位 1 次 → 每个设计 1 次 2K 提取。

| 项目 | 结果 |
| --- | --- |
| 设计数量 | 54，全部成功，无失败项 |
| 生成调用 | 1 次清理 + 54 次提取 |
| 放大局部参考 | 生效，警告为该设计“只占原图约 2%，已放大局部参考图重画” |
| 单张尺寸 | 1254×1668 至 1671×1583（长边约 1.2k 至 2.0k） |
| 白边指标 | 紧贴透明区的白色像素占主体比例：平均 0.13%，最高 1.2%，超过 1% 的 3 张（这 3 张本身是大面积白底文字设计） |

白边指标用脚本 `tmp/exp/halo.py` 计算：取 alpha>0 的主体，找到近纯白像素，再看透明区域向外膨胀 4 像素后能碰到的白色像素比例。抽查两张 100% 局部截图，主体边缘直接过渡到透明，没有白色描边环。

清晰度说明：放大局部参考只是把这块设计放大给模型看清形状和文字，原图本身只有约 100×90 像素的部位不会因此多出真实细节。要实质提高清晰度仍然需要上传分辨率更高的原图；本轮不据此宣称清晰度达标，实际效果以用户自己的密图为准。
