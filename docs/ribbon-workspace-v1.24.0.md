# 丝带工作台 v1.24.0

本轮以干净main `60419aa`、网站运行源码`502e57d6`为基线，不改其他项目、编号或素材提取业务。用户明确选择：两端完整大图＋中段小图；AI只搭配底纹/细小装饰，原人物文字保持；允许明确选中的公司案例发送给现有Seedream。

## 已实现

- **两端主图。** 原端区固定为带高1.2倍，横向原图被端区宽度压小、中段反而更大。新v2按首图完整旋转比例分配端区，约束中段约为端图可见高度60%；不跨区或拉伸。正式11811×520合成横图例从端599×124/中1229×256改为端2077×432/中1244×259。数字来自自制480×100图案，不是用户Snoopy的画质验收。v1及已有下载不变；切入两端模式作品或新版本首次看整条，手动切细节不被同版本轮询重置。
- **AI首稿。** 配置就绪时可勾选“AI搭配底纹与装饰”；模型接收所选完整图案联系表、所选底图、可选明确案例。一次原生2048方图请求生成衬底，再由程序按正式尺寸排入原图案。案例必须当前排法匹配、固定字节校验，提交与外呼前双验；无案例不读取案例。普通查看不发模型，关闭AI则原素材合成；精修仍原流程和两次成功额度。
- **作品切换。** 点击立即清旧图/下载、显示读取状态，并取消/隔离旧请求与轮询；即使请求忽略取消且迟到，也不能覆盖新目标。失败空态可重试，不能显示上一作品冒充成功。
- **删除。** “我的作品”可删除，已删除列表可恢复；属于软删除，运行中阻止、跨员工拒绝，原版本和累计次数保持。实际删除/恢复后保留50小时，重复删除不续期，引用与下载租约继续保护文件。
- **布局。** 更多排法在固定高度弹层选择；保留14模式和案例，确认后回原画布位置。首稿/下载/回退工具条在画布上方；1366×768、1920×1080及125%等效视口检查。
- **图库与去重。** 图案/底图列表最多每页36张，分类与ID索引缓存、搜索分页保持选择。新上传按EXIF归正后的完整RGBA和画布精确复用，不近似合并。预览只筛候选，最终校验原图；坏源/坏预览不阻塞有效新上传，不改损坏旧行或版本。

## 测量与验证范围

在同一本机的合成HTTP页面使用2000图案＋1000底图：图案首开321→46.7ms，底图库233.1→64.4ms，图案重开636.2→38.6ms；DOM分别由2000/1000/2000张减到36张，开库无额外目录请求。是单次本机合成交互对照，不代表公网、模型或所有电脑速度。

旧库首次索引原先同步解码全部原图。对相同PNG字节、两份独立新DB、各100张旧图的成对合成测量：1024方图3.5732→2.0202秒，2048方图8.4685→2.4069秒；完整旧原图解码100→0，首次改为100张640预览建指纹。数据准备排除、本地暖缓存、无模型。后续负候选缓存不再解码预览；碰撞仍校验完整原RGBA。

历史无缩略图且编码不同的行，要在正常预览派生时补齐原图索引；不宣称所有旧行已索引。相似但不同颜色、尺寸、画布或像素不会合并；历史重复行不物理合并。

冻结后Windows `tests/ribbon`及三份HSD网关相关测试共589通过，0失败；TypeScript/build、API2项、完整浏览器smoke、AI首稿专属合成流程、3000项目录竞态/分页和两端预览定向检查通过。本机实际HSD页面已操作首稿、更多排法、软删/恢复、切回原版下载及额度。测试图片均合成、演示配置明确；业务截图/测量只存本机忽略目录。

## 模型与数据边界

当前DeepSeek仍只按文字规划，不能称已看图。Seedream可以参考图，但本次只生成新衬底，程序保证上传主体的像素来源和比例；提示词不能保证模型从不误加主体、字或水印。任意背景也不保证无缝，真实印花效果需要员工核对。正式长条超出模型直接整幅编辑范围，不能缩小重画后放大冒充正式母版。

首稿不占成功精修次数；失败不扣，实际接口用量仍记录，未知结果不自动重发。原文件、原版本、员工隔离、正式规格、50小时、单worker和另一网站保持。公司图、原稿、模型请求/输出、密钥、缓存和测量回执不入Git或Release。
