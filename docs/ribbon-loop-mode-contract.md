# 水平循环单元的排法合同

## 新建作品（seamless-unit-v2）

14 个选项都输出一个完整循环单元，成图高度与 DPI 使用作品绑定的内部配置。前景先确定单元宽度。普通纹理在已定宽度内按等比取样拼接，底纹不再把间距向整段纹理宽度取整。

| 选项 | 一个单元里的内容 |
| --- | --- |
| 整齐平铺、错位平铺 | 完整图案顺序逐行重复；错位平铺的隔行起点偏移半个平均位置。 |
| 随机散点 | 显式保存随机种子，每行包含所有图案，顺序、大小和二维位置有变化，逐个采用 ±9°、±18° 旋转并校验旋转后的边界。 |
| 单排重复、大小交替、正倒交替 | 单行首尾闭合；大小按 1:0.58、正倒按 0°/180° 交替，奇数数量采用两组相位。 |
| 两端主图、两端留白、整幅定位 | 分别保留两端大主图和中间小图、两端主体和中段空白、一张完整设计。整个面板重复。 |
| 左右分区、上下分区、分区拼接 | 默认等分为两个或三个区域，各区可绑定独立底纹来源及底色。 |
| 上下边饰 | 一张主图即可生成连续边线，可另选完整边饰条，附加图案在上下边带循环。 |
| 组合循环 | 主辅图案等比排列并共享地面基线，独立场景底图按完整背景面板适配。 |

三个密度档的目标行高占比分别为 55%、72%、86%，常规行的间隔基准分别为 45%、28%、16%。模板配置及合法边界参与最终求解。默认多行布局使用 2、2、3 行，单行及分区模式保持各自结构。快照保留实际行数、间距、每个图案的有效尺寸和旋转等指标。两端主图、场景及大小交替使用共同适配系数保留主辅比例。

稳定图案编号绑定其所有副本。局部横移按有符号像素执行，触及其他图案或分区边界时拒绝保存。各分区记录底纹来源，边饰条单独记录素材来源。像素检测面向接缝和纹理异常，检查结果与实际印刷验收分别记录。

### 2026-11-04 实测

- 员工提供的素材目录含 27 张可读取的透明 PNG，背景目录有 4 张可读取的图片及 1 份无法解码的临时文件。私有输入、图阵和运行记录均留在测试电脑。
- 使用常规和预留素材组合，各生成 14 种排法 × 3 档密度，共检查 84 张 520px 高的生产尺寸 PNG。记录真实前景 alpha 像素总量与单元面积的比值。28 组三档对照逐档增加，最小相邻差为 5.67 个百分点。散点预留组合为 9.2%、16.1%、21.8%，对应疏朗、均衡、饱满。所有输入文件的 SHA-256 在运行前后相同。
- 该次 84 张中 81 张保留接缝或纹理提醒。其中 78 张有底纹拼接检查提醒，9 张有单元边界提醒，类别会重叠。提醒反映本组底纹的颜色、线条和较大图形特征，仍需结合实际印刷效果判断。另一次独立复核以不同组合生成 84 张，对照旧引擎同组 42 张，并对 882 组排法、密度与间距设置检查有效方向及散点边界。
- 复核修正了负向局部平移的实际位移、极限放大时的主辅比例、背景取样浮点舍入，以及完整场景之间的白色竖缝。局部移动碰到邻图时会提示调整，其他槽位保持原位置。

## 历史作品（seamless-unit-v1）

本表对应 `ribbon_backend/loop_layout.py` 的 `MODE_MATRIX` 和真实几何分支。新引擎为 `seamless-unit-v1`；旧的未标记、`design-rhythm-v1`、`design-rhythm-v2` 快照和下载保持原实现。单位高度、DPI、格式来自版本绑定的内部配置；宽度由完整图案序列计算，不从截图或图库案例推断。

| 排法 | 一个循环单元的真实内容 | 横向闭合和保留的语义 |
| --- | --- | --- |
| grid | 每行一套所选图案，按顺序完整放入 | 各行共用周期，仅分配间隔，不压扁图案 |
| stagger | 与 grid 相同，隔行错开半个平均位置 | 错位作为整个单元的相位，越界部分在外接缝续接 |
| scatter | 每行完整序列，固定种子的受限散点扰动 | 扰动随单元重复，保留安全间隙和完整内容 |
| single | 一行完整所选序列 | 左右各半个间隔，平铺后合为一个间隔 |
| alternating | 按选择顺序的大、小交替序列 | 长度取 lcm(2, 图案数)，奇数图案也闭合大小相位 |
| opposed | 按选择顺序的正、倒交替序列 | 长度取 lcm(2, 图案数)，倒置为 180°，不是镜像 |
| stacked | 前半所选图案在上行，后半在下行 | 两行共用周期；短序列可增加完整组数或均匀增加间隔 |
| bordered | 第一张为中间主图，其余为上下边饰 | 三行共用周期，边饰仅增加完整组，不改变主辅高度 |
| scene | 一套完整场景组合，首图主角，辅图按比例高低排列 | 全组以同一底线闭合，不拆开任何输入内容 |
| ends | 左主图、一次完整小辅图序列、右主图 | 整个面板循环；边界间隔不小于内部间隔，并至少为主图宽度的 35% |
| ends_open | 一张或两张完整端图，中间留白 | 有限面板语义；连续打印重复整个面板，不能承诺整条无限长丝带只有两个端图 |
| fullwidth | 一张完整设计，等比适配配置高度 | 有限整幅面板语义；连续打印重复整幅，不把原图拉伸成指定长条 |
| split | 前半图案在左区两行，后半图案在右区两行 | 完整左右区作为面板循环，各区宽度由各自完整序列决定 |
| panels | 左区两行完整序列、中区单行完整序列、右区第一张主图 | 完整三区面板循环，各区独立保持图案比例和层级 |

两端、整幅、分区不是无限单行重复的同义词。新快照保存 `kind=panel` 和明确提示，不悄悄改成平铺。横向偏移统一作为整个单元的循环相位；因此分区及留白随面板整体移动，只有外接缝可以分开图案，内部区界不裁切内容。纵向偏移只在各行安全区域内移动完整图案。

疏密同时改变高度目标和间隔目标；显式大小、间距、旋转仍进入真实几何路径。所有尺寸由可见内容（包括 alpha=1 的微弱装饰）整体等比派生，只移除全透明外边。宽图保留原比例，通过增加周期宽度容纳，不能靠缩小到旧固定宽度来伪装完整序列。

共同周期先取各行最长的自然完整序列。较短行尽量放入完整组数，再均匀分配剩余间隔；不独立取整成不同周期。可选底纹周期把总宽度向上取为底纹周期的整数倍；仅增加完整组或间隔。外部指定的更大周期也遵守此规则。自然宽度、实际宽度、每行组数、真实序列及构造验证均保存在私有版本快照。

本地仍限制任一边最多 16000 像素、母版和中间图不超过 4000 万像素、图案放置总数不超过 4800。超出时明确失败，不删除选择、不截断序列、不变更内部高度或压缩宽高比例。测试使用专属合成图案；几何测试通过不等于真实印刷验收或底纹已无缝。
