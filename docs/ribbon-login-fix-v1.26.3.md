## 修复行为

- 云端同一实例正常重启保持有效登录。登录签名由专属私钥分域派生，绑定实例和主要凭据；不把加密主密钥直接用作签名，不新增明文秘密文件。无法安全读取时拒绝启动。
- 员工登录仍有八小时绝对期限，管理员重新签发Cookie不能延长；匿名、其他员工、跨来源仍受后端限制。主要凭据、私钥或实例上下文更换会使旧登录失效。首次从旧随机Cookie切换仍需登录一次。
- 页面写凭证仍随进程更新。只有服务端明确拒绝、尚未受理的 `page_token_expired` 才读新令牌，携带原请求体和幂等键重试一次；已受理或结果未知的模型操作不重发。
- 短暂读取失败保留作品及输入，可点重新连接。真正401停止操作，旧请求迟到不会覆盖新状态。
