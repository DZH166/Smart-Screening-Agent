# 丝带设计接入说明

## 员工怎样使用

1. 从原网站登录，点击左侧「丝带设计」。不需要另注册账号。
2. 上传图案或从素材库选择，从14种排版中选择一种并选底图，然后生成首稿；原6种保留，其他在「更多排法」。带「示例」的素材和输出规格不是正式生产配置。
3. 可以更换所选素材与排版，或用一句话提出修改。每个作品最多完成两次成功精修；一次失败不占次数。首稿不占精修次数，AI 底图不占该额度。
4. 可以退回当前版本的父版本。回退不退还已用次数，也不删除分支记录。
5. 选中需要的历史版本再下载；下载始终对应该版本的 PNG。

选择排版时，可点每张样式卡旁的「查看案例」，查看公司图库里的对应例子和一句话说明；「查看全部案例」可对照不同排法。查看不会改变当前选择，不调用模型，也不占精修次数。关闭后继续原来的操作。

当前提供14种可生成选择。原六种为整齐平铺、错位平铺、随机散点、单排重复、两端主图、分区拼接；「更多排法」中新增上下边饰、组合循环、整幅定位、大小交替、两端留白、左右分区、上下分区、正倒交替。旧两端主图仍在中间铺小图，旧分区仍是三段；新选项补充留白和两区，不改旧作品规则。

图案按选择顺序使用：上下边饰至少两张，第一张是主体、其他是边饰；左右/上下分区至少两张，前半图案用于左/上区、后半用于右/下区；两端留白选一张或两张；整幅定位只选一张完整设计，不拉伸、不循环。组合循环用多图组成高低组合，想保留原场景关系则上传完整组合图。正倒交替是旋转180度，不是镜像。整幅定位、两端留白不使用重复间距。

图库13张例图帮助理解结构，不自动成为生产素材；两种底纹、完整场景和整幅外形需自备素材，工具不自动照搬案例内容。查看不发模型请求、不改选择或扣次数。真实印刷、颜色和循环接缝效果仍需业务检查。

「不占精修次数」不代表模型调用不收费。修改成功但主观上不满意仍算一次成功精修。一次要求包含多项修改时，全部完成才提交版本和扣次；模型无法完成的要求会说明原因，不用演示图片冒充成功。

个人作品、历史版本和个人上传素材保留 50 小时；成功生成、精修或回退后重新计时。处理中、正在查看或下载的资源不会被清理，仍被未过期作品引用的素材会保留到引用结束。共享素材库、模板和输出配置独立保存。图号、素材提取和丝带设计共同使用同一个保留时长配置。

请使用原浏览器重新登录后找回个人作品；同一个员工访问码不会把不同浏览器的资料合并。下载后文件保存在自己电脑，服务器不接 OSS。

## 管理员设置

- 「Key 账本 → 丝带设计 · 模型服务」只有一条路线：**DeepSeek ＋ Seedream**，沿用 Key 账本里已启用的两项配置。新功能默认不启用付费模型，确定性首稿可先使用；启用后会显示实际沿用的语言模型与图片模型 ID。
- OpenAI 路线暂不在界面提供（后端代码保留，便于以后启用）。原因：线上服务器无法直连 `api.openai.com`，且当前决定先只用 Seedream；界面不再预置任何 OpenAI 字段，避免误选。
- DeepSeek＋Seedream 沿用现有已启用的两项设置，不复制或更改它们的 Key。共享 DeepSeek 池的限流和用量记录保持。
- 保存设置不产生调用，也不代表已验证效果。任务绑定提交时的配置，配置改变后旧任务会明确失败，不悄悄换用另一套模型。
- 「功能区 → 丝带设计」打开员工工具；「素材与规格维护」供管理员维护共享库、模板及固定输出规格。修改会新增版本，不覆盖历史。

当前生效的输出配置（2026-10-29 与设计师确认）：**300 DPI、RGB、PNG**，含出血总高 **4.4 cm**（成品 3.8 cm，上下各 0.3 cm 出血），长度方向**不留出血**；画布按 **100 cm 长**（11811×520 px）落图。长度本身不固定，如常用长度或循环单元确认后，改输出配置即可，不需要改代码。旧的 2400×600、150 DPI 演示配置已停用但保留在历史里。

## 运行与接口

React/TypeScript 作为独立工作区挂载在 `#ribbon`，样式放在 ShadowRoot 中。构建命令：在 `ribbon_frontend/` 执行 `pnpm install --frozen-lockfile`、`pnpm build`。产物为 `hsd_tool/static/ribbon/ribbon.js`，按需加载；切走后保留界面并暂停轮询。

FastAPI 通过 a2wsgi 接入原 Flask 服务，公开接口统一为 `/api/ribbon/*`，不新增公网端口。原网站先检查员工会话、来源及写操作令牌，再在 WSGI 私有环境里传入身份；不信任浏览器提供的 owner/role。管理接口再次检查管理员权限。原项目的独立测试登录不在员工入口开放。

主要路径：

| 路径 | 作用 |
| --- | --- |
| `GET /api/ribbon/auth/me`、`/config` | 当前身份及可用配置 |
| `GET/POST /api/ribbon/assets` | 素材列表、上传单张素材 |
| `GET /api/ribbon/templates` | 候选排版及版本 |
| `GET /api/ribbon/layout-examples` | 14种排版说明与13张精挑图库案例元数据，只读 |
| `GET /api/ribbon/layout-examples/{code}/image?v={digest}` | 登录后读取固定完整性校验的教学预览 |
| `GET/POST /api/ribbon/designs` | 个人作品 |
| `POST /api/ribbon/designs/{id}/generate`、`/refinements` | 首稿与精修，必须提交幂等键 |
| `POST /api/ribbon/designs/{id}/rollback` | 按预期当前版本回到父版本 |
| `POST /api/ribbon/background-jobs` | 生成底图 |
| `GET /api/ribbon/jobs/{id}` | 本人任务进度 |
| `GET /api/ribbon/versions/{id}/preview`、`/download` | 绑定版本的预览和 PNG |
| `/api/ribbon/admin/overview`、`/templates`、`/output-profiles` | 管理员维护 |
| `GET/POST /api/admin/ribbon-settings` | 模型设置，保存需 `expected_revision` |

丝带单张上传沿用原工程的 PNG/JPEG/WebP、20 MiB、4000 万像素保护，不改变图号 ZIP 的不限固定字节上限规则。排版按原图案确定性合成。文字编辑由语言模型形成受控计划，再执行参数或图片编辑；没有发送编号表、AI 原稿或其他工具的业务数据。

数据库位于专用数据目录的 `ribbon/ribbon.sqlite3`，SQLite WAL；图片及任务记录也只在这个子目录。一个持久化 worker 顺序执行任务，原网站仍只运行单 Gunicorn worker。正常退出先等待请求、下载及已发出的调用收敛，再停止事件循环。服务重启后已有持久队列自动检查恢复，结果未知的付费请求不自动重发。

配额、当前版本、幂等键、父版本、任务尝试号与扣次事件由服务端事务控制。母版、预览、引用素材和模板缩略图验证哈希；被替换后拒绝使用，不为通过检查重新计算基线。

清理只针对经验证属于本模块的路径。删除中断有持久重试队列。旧请求仅保留最小幂等墓碑（owner、幂等键、请求哈希），避免过期后重放再次付费；不含图片、修改文字或 Key，但这些记录会随提交数增长。

## 已知边界

- 公司图库预览独立部署在实例设置目录`ribbon_layout_examples/`，不进入Git、公开发布包、个人作品清理或模型输入。仅允许本轮精挑图号与对应完整性摘要；图片缺失或变化时说明仍可看，图片明确提示不可用，不自动从外网获取或替换。它们是排法参考，预览水印保留，不能用来确定正式尺寸或证明无缝接缝。

- 本轮使用合成数据和模拟模型接口验证流程，没有进行付费模型效果验收。两条路线的清晰度、文字保真和接缝效果仍需实际试用。
- 参数调整目前作用于全部图案；指定单个图案位置或缩放时会要求进一步说明，不能只执行半条要求。
- 整幅模型编辑可能改变独立图层能力；后续不能执行的操作会明确说明。模型尺寸限制见[模型调用说明](ribbon-providers.md)。
- 单进程内存与磁盘检查降低资源争用风险，不等于任意并发量都可处理。多实例和外部数据库尚未验收，不能增加 Gunicorn worker 数量。
