# v1.28.0 丝带工作台精简

2026-11-08。用户明确取消丝带精修，范围覆盖前端入口和后端新任务能力；素材提取的独立单图精修保持。本记录中的候选实现通过最终源码、Linux与上线验证后，才表示实际交付。

## 使用方式

选择图案，选择排版与底图，生成作品，下载。已有作品想换效果，修改选择后点击“生成新作品”；创建独立作品，旧作品和版本下载不覆盖。试排按下一份新作品的当前规格和v3引擎，历史画布按自身快照。原图案、文字、图库、案例、图案用途、首稿AI底图、作品删除/恢复、历史下载与回退保持。

精修侧栏、空态、修改要求、目标选择与覆盖框、建议、执行回执、次数显示以及相关说明删除。主区域改为设置和宽画布两列，不另加替代的AI编辑步骤。旧历史版本使用中性版本名称，详细记录按需查看。

## 真实停用及兼容

- 新精修POST明确410，所属作品先鉴权；不规划、不建任务/版本、不扣次。公开当前编辑能力为空，精修上限为0。
- 仅保留已接受旧任务执行、历史文件、提交校验和回退所需内部兼容。不可变旧快照不改写，不删除历史额度字段或数据库列。
- 旧页面本地未知提交只通过owner限定的幂等键GET读取已有任务；未知404、过期410，网络失败只重试读取。不会重发已退役POST，返回的作品不符时拒绝恢复。
- 创建新作品的响应未知时不盲目重试创建；已受理的生成任务仍按原幂等键恢复，不重复调用模型或覆盖原作品。
- 图片能力与历史文字能力分开：图片模型和Key可独立使用；历史规划在自身入口检查语言模型和Key。共享DeepSeek、素材提取和图号助手配置不删除。配置版本指纹、调用前检查、凭据保护、隔离、50小时与单worker保持。
