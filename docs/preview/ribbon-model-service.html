怎么填写与常见问题
  1. 丝带默认沿用素材提取里的火山方舟 Key 与图片模型，不填也能用；这里填写是为了让丝带单独使用另一套配置。
  2. 填写 API Key 与图片模型 ID 后保存，两者都填才会切换到丝带专用配置；只填一项不会生效。
  3. 点“删除配置”会清空丝带专用配置，自动回到沿用素材提取的状态，不影响素材提取本身。
  4. 保存设置不会调用模型；启用后员工点“生成底图”或“精修”才会产生调用与费用。
  5. 切换配置后，正在处理的任务会明确失败并保留原版本，不会用新配置偷偷续跑。

图片服务使用火山方舟北京接口；DeepSeek 的文字理解配置独立保存在 DeepSeek 页面。
