# 丝带排版案例：实现与验证记录

日期：2026-10-29（Asia/Shanghai）。用户授权把已审阅公司图库案例及简单说明加入排版选择。本轮只增加说明入口，不修改六种排版算法、模型调用、300DPI输出、额度、版本、下载和个人资源保留规则。

## 当前实现

- 每个排版有独立「查看案例」，按模板`mode`匹配，支持管理员自定义模板ID。查看不改变选择；全部案例提供横向比较。
- 图案按需加载，支持整条/放大、错误和缺图重试、键盘退出与焦点返回。切功能或身份关闭窗口并清除当前工作区案例缓存，未完成目录请求取消。
- 例图来源为公司图库已授权的1200像素预览。保留完整画面和覆盖水印，不重绘、裁切或上传模型。不是生产素材、正式输出规格或真实无缝效果证明。

## 图片与权限

图库受访问码保护，因此图片不提交公开Git或Release。代码只记录图号、教学文字、宽高、精确字节数和SHA256。图片安装到`<实例设置目录>/ribbon_layout_examples/`，服务账号私有目录0700、文件0600；共享教学资源不参与50小时个人任务清理。

`GET /api/ribbon/layout-examples`和`GET /api/ribbon/layout-examples/{code}/image?v={digest前16位}`沿用宿主员工登录。图号只接受固定白名单，图片只读普通文件且逐次验证完整字节，先验证登录和内容再处理HEAD/304；错误不缓存。不存在任意路径、上传、图库外链或付费接口。安装缺失/被修改时目录返回不可用，不能用其他图顶替。

部署时仅传输上述10张精挑预览，逐一核对`hsd_tool/ribbon_examples.py`固定摘要与字节数；原文件存在只接受相同内容，不覆盖未知文件。不得把图库访问码、其他公司图稿、日志、设置或密钥加入传输包。公开Linux源码包也明确拒绝`ribbon_layout_examples/`目录。
