# 丝带图库排法补全（v1.21.0）

日期：2026-10-30，Asia/Shanghai。本轮是实际排版能力补全，不更换图片模型，不把案例图片作为生成素材。

## 重新检查的范围

公司图库当时显示36951张、每页100张。本轮在第1、70、140、210、280、370页跨区段检查，实际取得并逐图查看344张预览（100、81、100、25、25、13）；第70页映射有100条，但只取得81张，不将未取到的19张计入。另放大1200像素的HSD53659、HSD31412、HSD31296复核结构。私有原图、联系图与对应元数据只保存在本机忽略目录，不进入Git或公开Release。

这是分层抽样，不是遍历全库，也不声称所有排法已经穷尽。节日/人物是题材；格子/圆点/条纹多为底纹，不据此堆出同义排版按钮。

## 从6种选择补到14种

| 新选择 | 图库证据 | 实际实现与边界 |
| --- | --- | --- |
| 上下边饰 | HSD68402、HSD68404 | 第一张为中间主体，其余为上下窄边饰，至少2张；不生成未知底纹 |
| 组合循环 | HSD68618、HSD61621 | 多素材高低组合后整组重复；单张完整场景保留原内部关系，不自动理解/重建场景 |
| 整幅定位 | HSD67181、HSD61511 | 单张完整设计默认保持比例居中，不循环、不拉伸；比例不同允许留白 |
| 大小交替 | HSD53659 | 沿长度一大一小轮换所选图案，不把半身人物改画成全身 |
| 两端留白 | HSD51045、HSD60834、HSD31517 | 1图双端或2图左右，中央只保留所选底图；是旧两端家族的补充变体 |
| 左右分区 | HSD68027、HSD60818 | 前半素材左区、后半右区；至少2张；两区互相隔离，不自动创建两种底纹 |
| 上下分区 | HSD31412 | 前半素材上区、后半下区，约各半幅，区别于窄边饰；至少2张 |
| 正倒交替 | HSD31296 | 单排相邻图案0/180度轮换，不镜像、不伪称上下两行 |

原整齐/错位/随机/单排/两端主图/三段分区算法保留原像素。14是可选项数量；其中留白和两区是已有视觉家族的补充，不宣传为14个互不相关的新家族。

## 实现与数据保护

- 新模式有独立内容盒适配、真实缩略图、磁盘估算和参数路径。新模式不暴露无效rows；整幅定位/两端留白不使用step_ratio或重复间距。仅原间距的空操作澄清，不新建版本、不扣次；混合真实缩放或真实改选仍可完成。
- 生成、改选精修及持久任务均校验素材数量；不得静默只用第一张、忽略其他所选图案。默认完整适配；员工明确放大、偏移后可能裁出画面，分区不会跨入另一侧。
- 旧库只追加8个新默认模板，不覆盖旧模板、管理员停用、自定义ID冲突、输出配置和作品版本；重复初始化幂等。旧六类黄金像素摘要保持。
- 原模型、Key、50小时、单worker、两次成功精修、父回退、幂等和版本绑定下载保持。13张教学图仍只放实例私有目录，登录与SHA校验先于读取/304，不进入模型或素材库。
