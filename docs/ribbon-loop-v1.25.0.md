# 丝带循环短图 v1.25.0：实现与验证记录

记录日期：2026-11-04。本文件记录当前工作区已经实现及已取得的本地证据；发布、真实模型和 Linux 验收状态见文末。原丝带工程、产品文档、交接包和历史说明保留。本轮没有把截图、案例图片或图库尺寸推断为正式规格。

## 输出合同

新首稿绑定 `seamless-unit-v1`。程序直接生成一个完整的水平循环单元，宽度根据完整图案序列和底纹周期计算。下载内容是这个单元的原尺寸 PNG。页面的连续效果将同一版本预览并列展示三次，不再生成一张固定长条后任意截取短段。

高度、DPI、格式及演示标记仍来自版本绑定的内部配置。原配置完整保存在 `output_profile_source`；`output_profile.width` 记录这一版本实际计算的宽度。原正式配置的 520px 高度和 300DPI 不因本轮改变；11811px 的原配置宽度作为来源记录保存，不再要求新循环单元填满该宽度。像素尺寸、来源配置和下载文件必须相互一致。

完整可见内容由所有 alpha>0 像素界定，包括 alpha=1 的微弱装饰。程序只在派生排版时排除外部全透明留边，再将整份人物、文字、内部底板和装饰等比排入。宽图通过增加单元宽度容纳；资源超限时明确失败，不能压扁、删掉所选图案或截断序列。横向偏移是整个单元的循环相位，跨外接缝的内容在另一端续接；纵向偏移限制在安全区域内。

底纹存在时，总宽度向上取为底纹整数周期的倍数。增加宽度只增加完整图案组或间隔，不重新压缩图案。纯色背景直接使用完整图案序列的自然宽度。单元任一边最多 16000px，母版和中间图最多 4000 万像素，图案放置总数最多 4800；底纹预检还包含重叠工作区，不能到生成后才用拉伸或截短绕过限制。

## 14 种排法的循环含义

详细几何合同见 [ribbon-loop-mode-contract.md](ribbon-loop-mode-contract.md)，对应代码 `loop_layout.MODE_MATRIX`。

| 排法 | 一个单元包含的内容 | 闭合方式 |
| --- | --- | --- |
| grid | 每行完整所选序列 | 各行共用周期；列按各图实际宽度对齐 |
| stagger | 每行完整所选序列 | 隔行错开半个平均位置，错位相位随单元闭合 |
| scatter | 每行完整序列与固定种子的受限扰动 | 整套散点重复，保留间隙和完整内容 |
| single | 单行完整所选序列 | 两侧半个间隔在相邻单元间合为一个间隔 |
| alternating | 完整顺序及大小交替序列 | 序列长度取 lcm(2, 图案数)，奇数图案也闭合大小相位 |
| opposed | 完整顺序及正倒交替序列 | 序列长度取 lcm(2, 图案数)，倒置为 180°旋转 |
| stacked | 前半图案在上行、后半在下行 | 两行共用周期，短行增加完整组或分配间隔 |
| bordered | 首图为主图，其余为上下边饰 | 三行共用周期，保留主辅高度 |
| scene | 首图主角及一套完整辅图组合 | 整组共用底线并循环 |
| ends | 左主图、一次完整小辅图序列、右主图 | 整个有限面板重复；接缝保留主图之间的间隔 |
| ends_open | 一张或两张完整端图及中间留白 | 整个有限面板重复 |
| fullwidth | 一张等比适配高度的完整设计 | 整幅有限面板重复 |
| split | 左区前半图案、右区后半图案，各为两行 | 完整左右分区作为面板重复 |
| panels | 左区两行、中区单行、右区首图主图 | 完整三区作为面板重复 |

后五种排法保存 `kind=panel` 和相应提示。两端留白在连续打印中会重复整个面板，不能承诺任意长丝带只出现两个端图；整幅定位也会重复整幅面板。分区和留白随横向相位整体移动，不在内部区界裁掉图案。14 个选项保留各自真实几何分支，不把所有选项改成同一种网格。

## 模型与程序的职责

DeepSeek 仍只接收文字和受控配置来规划编辑，不能称其已经看图。Seedream 首稿一次请求生成原生 2048×2048 的搭配底纹和细小辅助装饰；人物、文字及完整主体由程序从原素材叠放。新引擎关闭整幅母版 AI 重画，精修通过独立图案、独立底纹或真实参数修改后重新计算完整周期。

AI 辅助关闭时沿用所选素材合成。启用时只发送当前选中的图案联系表、当前底图以及用户明确选择的可选案例。案例必须属于实例私有白名单、匹配当前排法并通过固定字节校验；普通查看、未选择案例或未启用 AI 不发送案例。没有扩大到全图库、其他员工素材或凭据。首稿不自动追加精修；真实接口失败和未知结果不降级为库图伪成功，也不盲目重发。

提示词要求不新增主体、文字、水印或标志，但提示词不能保证任意模型结果都遵守。程序背景检查也不能识别全部文字或语义主体。真实生成是否符合设计意图，需要结合实际输出判断；合成替身验证只证明工程路径。

## 底纹周期化与检查

`loop_background.py` 使用确定性的最小误差重叠接缝。其方法参考 [Efros/Freeman 的 Image Quilting](https://people.eecs.berkeley.edu/~efros/research/quilting.html)，当前实现只处理背景：

1. 按来源宽高比和目标高度建议周期，预留约单元宽度 1/6 的重叠区。方形底纹配 520px 高度时，建议周期为 446px。过大的自然周期明确拒绝，不把它静默截成可用周期。
2. 对来源取中心窗口并以同一个比例采样，形成“周期宽度＋重叠区”的工作图。透明像素先按明确底色合成再缩放和比较，隐藏 RGB 不影响接缝；全透明底纹拒绝处理。
3. 在左右重叠区上，用颜色及横纵梯度误差寻找逐行最小成本路径。路径两侧直接复制来源像素。工作图中重叠区之外的中心区域保持采样后的原像素，不做大范围模糊、镜像、横向拉伸、渐变涂盖或接缝遮挡。
4. 将得到的一个整数宽度周期逐份原样复制到完整单元，再叠放原前景。不存在对每一份底纹单独拉伸或不等宽取样的步骤。

检查包含原生高度每一行的接缝两侧颜色和横纵梯度、单行极值、来源图和工作图中的较大高对比连通区域，以及 1/2/4/8/16/32px 色带的多尺度比较；尺度按实际宽度限制，多尺度色带最多采样 1024 行。相同边缘一列并不足以通过；接缝旁的色带和内部接缝同样参与检查。

流水线先检查完整底纹，包含随后会被前景遮住的区域，再检查最终合成图。最终合成图检查是补充证据，不能以主体挡住接缝来代替背景自身检查。版本保存来源裁取窗口、等比采样比例、重叠宽度、接缝路径、原像素保留区域、逐项报告和结果摘要。

| 结果 | 当前含义 | 保存和后续操作 |
| --- | --- | --- |
| `checked` | 几何构造和当前像素检查通过 | 可查看、继续精修、回退及下载 |
| `needs_review` | 接缝、色带或较大高对比图形存在疑问 | 保存真实结果及提示，可查看连续效果或调整底纹、间隔、位置 |
| 解码、全透明或资源错误 | 无法完成可信处理 | 任务失败，原版本保留，不扣成功精修次数 |

`production_verified` 始终为 `false`。`checked` 只表示工程检查范围内通过，不代表审美、文字正确性、真实无缝感或印刷验收。较大高对比连通区域检查不是 OCR，也不能识别全部低对比主体、小文字或语义重要性；多尺度抽样也不是逐像素的全部视觉证明。页面说明为“像素检查不代替设计师的视觉和印刷验收，可按需查看连续效果。”

## 不可变版本、额度与页面

参数、图案比例、底纹或排法改变后，只解析待创建的新版本，重新计算周期；不套用父版本宽度。旧的未标记、`design-rhythm-v1`、`design-rhythm-v2` 继续使用原渲染路径，其配置、尺寸和已有下载不重写。历史精修和父版本回退保持原语义。

版本保存几何输入签名、完整源素材顺序和摘要、原配置来源、实际宽高、工程报告、母版摘要及独立预览摘要。提交和检查点恢复核对这些记录，并重新核对被引用素材归属和完整字节；报告缺失、结论与检查项不一致、来源顺序或摘要变化不能提交为新版本。下载按不可变版本 ID 和母版摘要绑定，不重新查当前版本指针。

首稿免费；每作品累计最多两次成功精修；失败不扣、回退不返还。整周期偏移或其他编辑若最终与父版本完整 RGBA 像素相同，不创建版本或扣次。服务端事务继续控制并发幂等、最后一笔额度、当前版本及员工隔离。保留期仍为统一的 50 小时，活动任务、引用和下载租约的保护保持，未修改其他业务。

页面默认显示单个循环单元，可按需切换连续三次效果和接缝指示。三份连续图复用同一版本预览 URL；切换效果、接缝指示、尺寸变化及同版本轮询不重新获取母版。下载仍为一个原尺寸单元。来源配置等技术信息折叠展示。切作品立即隔离旧请求、图片和下载；迟到响应不能把旧作品冒充新作品。
