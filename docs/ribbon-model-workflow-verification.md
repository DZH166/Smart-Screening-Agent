## 职责与实际改动

- DeepSeek按文字、所选图案名称/顺序、排法、当前参数和实际能力生成JSON计划；不发送图片给它审图。至多8项，关闭thinking，服务端再检查，不把模型意见当权限。
- Seedream按输入要求生成底图、编辑明确指定的独立图案或底图。首稿与参数修改由程序合成，不重画原图案。正式11811×520长条超出直接整幅编辑范围，禁止先缩小重画后放大冒充正式母版。
- 员工能输入底图要求；图案顺序名称可对照。配置/版本提供动态editing投影，旧作品按自身规格；职责细节按需展开，不新增审核或复杂配置。
- 图片调用前检查全计划及所有输入资格，避免后项明显不支持却先对前项付费。执行时重新验证已捕获输入字节。模型输出检查原生尺寸/透明；错误输出不缩放顶替、不自动重试。
- 参数回显、抵消式修改、相同选择无变化时澄清，不新建版本、不扣精修次数；真实改选和混合有效修改保留。未知接口结果不重发；失败不扣业务次数但外部调用仍可能计费。

## 验证范围

Provider、服务和浏览器合成检查分别覆盖JSON/尺寸/失败/权限/能力边界、不可变旧版本与真实改选、背景要求传递/失败重试/无配置/本地替身标识。首次统一回归3项旧测试曾假设“相同选择也应成功扣次”，现改为真实切换排法，保持它们验证保留期和分支下载的目的；不放宽无变化保护。

只读确认线上已配置DeepSeek＋Seedream且ai_ready=true，没有读取/输出API Key或改变设置。真实联调使用专属员工会话和自制透明小花，不使用公司图库/业务样本，也不用留待后续的10.12。

计划经真实员工API完成：按要求生成底图→原素材V0（不调用模型）→DeepSeek调参V1→DeepSeek规划并由Seedream修改小花V2→回退V1且额度仍2→三版本下载尺寸/DPI/摘要一致。约4次外部请求（1底图、2计划、1图片编辑），每次提交前保存请求意图和幂等标识；未知提交立即停止，无自动重发。完整请求、用量、request ID、图像及带身份的逐项记录只留私有回执；公开仅汇总验证步骤、数量、耗时与边界。

## 员工开始实测

1. 打开网站「丝带设计」，上传或选择图案，选排版和底图。
2. 需要新底图时输入要求并点「AI生成底图」；使用已有底图可直接生成首稿。
3. 在文字精修里写「第一个图案」或图案名称，再写具体要求。缩放、间距等由程序修改；图案/底图内容才交给Seedream。
4. 查看保存结果，按需回退或下载指定版本。首稿不占精修次数，每份作品最多两次成功精修；请在50小时内下载。
