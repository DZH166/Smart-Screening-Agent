## 职责与实际改动

- DeepSeek按文字、所选图案名称/顺序、排法、当前参数和实际能力生成JSON计划；不发送图片给它审图。至多8项，关闭thinking，服务端再检查，不把模型意见当权限。
- Seedream按输入要求生成底图、编辑明确指定的独立图案或底图。首稿与参数修改由程序合成，不重画原图案。正式11811×520长条超出直接整幅编辑范围，禁止先缩小重画后放大冒充正式母版。
- 员工能输入底图要求；图案顺序名称可对照。配置/版本提供动态editing投影，旧作品按自身规格；职责细节按需展开，不新增审核或复杂配置。
- 图片调用前检查全计划及所有输入资格，避免后项明显不支持却先对前项付费。执行时重新验证已捕获输入字节。模型输出检查原生尺寸/透明；错误输出不缩放顶替、不自动重试。
- 参数回显、抵消式修改、相同选择无变化时澄清，不新建版本、不扣精修次数；真实改选和混合有效修改保留。未知接口结果不重发；失败不扣业务次数但外部调用仍可能计费。
