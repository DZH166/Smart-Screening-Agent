## 实现与边界

- `/admin` 支持每行一个 Key，最多保存100个，标签、启停和删除；原有单 Key 读取保留，首次成功保存才原子迁移为逐 Key DPAPI 加密的 v2。保存失败不覆盖原配置，非 Windows 不降级为明文文件。
- Key 与尾号不回显，批量输入默认遮盖并在提交前清空。可用只表示本地未暂停；未实际调用的 Key 显示“待调用”，不冒充接口验证。
- 可用 Key 轮询；单项最多两次实际尝试。认证/余额异常暂停该 Key；修复后可先停用再启用恢复。网络/服务故障在原 Key 上重试，429结束当前项并冷却该 Key 60秒，不立即换 Key 规避限流。多 Key 不扩大官方账号额度。
- 调试为2秒增量读取，展示阶段、Key 标签、尝试、等待、耗时、返回类型及本地转人工原因；状态/费用约10秒刷新。隐藏页面停止轮询。服务端只保留进程内最近2000条，页面最多500条，重启/缓冲丢失有提示。
- 调试记录仅有允许的脱敏字段；不保存图像、请求体、提示词、本机路径、密钥、任意异常文本或模型隐藏思维。仅展示结构化结果和服务端判定，不提供完整请求历史。
- 每 Key 用量是本进程统计，累计账本另行保留；失败与未知用量继续计入，USD只是估算。删除 Key 不回滚进程总量。没有新增费用上限。
- 管理员页面/API/静态资源仅主机访问。Origin、Token、任务忙碌和配置版本冲突检查保留；员工无累计费用或主机管理权限，管理员观察过程不获得其他员工任务修改/原稿读取权限。
- 当前协议仍为 `hsd-ai-review-2`；实现签名扩至10个模块，源码与冻结程序一致。旧资格按实现变化失效，本次未预置或激活业务自动通过资格。
