# 智筛 Agent · HSD 图号助手

单机 Windows 图片与 AI 设计文件对应编号工具。用户确认的范围：固定 XLSX 模板 A 列编号/B 列图片；HSD + 四位新流水号；保留已有编号；只对成功匹配的空白编号行填号；疑难项人工复核；非破坏性输出副本。

当前版本：`v1.2.0`（2026-10-15，**DeepSeek 评估版**）。Windows 便携程序见 [GitHub Releases](https://github.com/DZH166/Smart-Screening-Agent/releases/latest)，解压整个文件夹后双击 `HSD图号助手.exe`，不需要安装 Python。操作步骤见 [使用说明](使用说明.txt)，版本记录见 [CHANGELOG.md](CHANGELOG.md)。

本版增加“本机匹配 → DeepSeek 二次复核 → 剩余人工审核 → 摘要 → 导出”。AI 复核默认关闭，启用后仍处于评估模式：**AI 只给建议，疑难项仍由员工确认**。发布包不预置业务自动通过资格，不承诺减少多少人工审核。

## 运行与构建

使用 Python 3.12；在项目目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m hsd_tool
.\.venv\Scripts\python.exe -m pytest tests -q
.\build.ps1
```

v1.2.0 便携构建输出位于 `dist/v1.2.0/`，解压发布包后双击其中的 exe。程序只监听 `127.0.0.1`，随机本地端口，界面资源均离线加载。本机匹配无需联网；启用 DeepSeek 复核时需要联网并产生 API 费用。无需安装 Illustrator 来读取已有 PDF 兼容预览；不能渲染的 AI 会明确列为异常。

便携包验收需要本机已有 `测试样本/10月表格.xlsx` 和 `测试样本/10.10.zip`，不会把它们加入发布包。先启动刚构建的 exe，使用独立数据目录并保持 AI 复核关闭；在另一 PowerShell 窗口运行验收：

```powershell
& '.\dist\v1.2.0\HSD图号助手\HSD图号助手.exe' --no-browser --port 8804 --data-dir '.\tmp\v12_portable_data'
```

```powershell
.\.venv\Scripts\python.exe tools\verify_portable.py http://127.0.0.1:8804 --bundle 'dist\v1.2.0\HSD图号助手' --work tmp\v12_packaged_validation
.\.venv\Scripts\python.exe tools\prepare_delivery.py --result 'tmp\v12_packaged_validation\验收结果.json' --notes 'tmp\v12_packaged_validation\验收说明.txt'
```

`verify_portable.py` 核对实际运行的冻结程序及构建指纹，用缺号副本验证编号、表格局部更新、原稿不变和导出 AI 的原始字节。`prepare_delivery.py` 需验收成功后运行；先根据真实验收结果编写 `--notes` 指定的说明文件。它会再次校验构建一致性，生成 `交付/v1.2.0/` 下的 ZIP 和 SHA256。验收后若改动构建输入，应重新构建并验收。这组命令验证本机匹配与打包导出，不自动取得 AI 业务放行资格。

## DeepSeek 设置与数据范围

1. 点击右上角“AI 复核设置”，填写自己的 DeepSeek API Key，勾选“启用 DeepSeek 二次复核”，保存。
2. 密钥输入框始终不回显现有密钥；留空保存会保留已有值，保存或关闭窗口会清空输入内容。Windows 使用当前用户的 DPAPI 加密保存，不写入日志、导出结果或 Git。保存成功只表示设置保存成功，不表示接口已验证可用。
3. 确认提示“验证未完成，AI 先给出复核建议，仍需人工确认”。导入批次后，后台自动执行符合条件的二次复核；已经完成本机匹配的批次，在页面允许时也可补跑。
4. 在待审核项查看 AI 的建议、对应候选和差异，再由员工确认或跳过。请求失败、额度不足、限流、网络异常或响应无效会保留人工处理，原有本机匹配结果仍可继续使用。

模型固定为 `deepseek-flash`，仅由本机后端调用 DeepSeek。发送内容是符合复核条件的表格图片、最多五个候选的预览、保持完整覆盖的长条分段以及比较要求与本地疑问原因；候选用任务内 ID 标识。**原始 XLSX、ZIP、AI 文件以及本机文件路径不上传**。图片中本来包含的文字仍属于图片内容，会随预览发送。

重复预览、重复表格图片、文件归属或编号冲突、损坏/无法读取的预览、多画板、无可信候选等不进入模型复核；源文件变化也不能用模型意见解除。关闭 AI 复核后继续使用纯本机流程。开发者可通过 `DEEPSEEK_API_KEY` 环境变量提供密钥，本机保存的密钥优先；清除本机密钥不会删除环境变量。

设置页显示累计调用量与费用估算，结果摘要显示本批用量。按已知 token 用量和程序记录的峰值单价，以 USD 保守估算，**不是账单，实际费用以 DeepSeek 账单为准**。请求用量未知时会单独提示次数，费用统计不完整，不将未知费用记作零。本版不设置费用上限或达到某金额后自动停止的开关。

价格依据于 2026-10-15 核对的 [DeepSeek 官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)：`deepseek-flash` 峰值价格为每百万输入 token 缓存命中 US$0.006、缓存未命中 US$0.30，每百万输出 token US$1.20。本工具统一用峰值单价估算，不推测实际调用时段折扣；价格可能调整，估算不替代账单。

## 模块

- `workbook.py`：流式读取 WPS 图片与行号，ZIP/XML 定点更新空白编号，不经普通表格引擎重保存。
- `matching.py`：安全读取 AI 文件夹/ZIP，渲染预览。先用几何特征验证，再对长条与重复纹样启用纹理像素验证；两条通道都必须通过多项独立证据的交叉检查，才会自动通过。
- `ai_policy.py` / `ai_images.py` / `ai_client.py`：复核资格、预览与完整分段、后台 DeepSeek 请求及结构化响应校验。
- `ai_settings.py` / `ai_usage.py` / `ai_registry.py` / `ai_workflow.py`：加密设置、用量记录、限定场景验证资格与后台任务。
- `service.py`：任务状态、编号规划、人工确认、文件校验、事务式导出。
- `server.py`：本机 HTTP 接口与原生文件选择窗口。
- `static/`：中文导入、复核、导出界面。

编号与文件名冲突采用保守处理，不覆盖原件。新编号只规避当前表格中的已用号；跨批次起始号由员工确认。缺图和跳过行不会分配新号。输出保留完整工作簿，其余 XLSX 内部部件原字节复制。

## 匹配与自动通过

本版沿用正式 `v1.1.1` 的本机匹配器，未混入本机另一份未发布的 47 自动 / 13 人工开发稿。

自动通过不是单一分数阈值，而是多证据交叉验证的结果：

- 几何通道：特征点匹配、仿射对齐、覆盖范围、像素误差与源图内容覆盖。
- 纹理通道：整条带多尺度平铺比对，要求像素均方根误差、明显变化面积、最大变化面积、最差区域、颜色分布与内容可解释性同时达标。
- 内容可解释性：画板上无法被匹配图案复现的有墨内容视为未验证内容，不允许自动通过。
- 唯一性：本批次存在同样接近的候选，或同一文件被多行指向时，一律转人工。

阈值由像素误差的物理含义与正例、易混淆反例的实测间隔确定，不针对某批样本调参，也不使用文件名、行号或样本答案作为匹配依据。

AI 的“相同”意见不等于通过。只有相应场景取得有效的独立业务验证资格，当前图片与源文件未变、全部细节可完整核验、模型明确确认内容/颜色/完整覆盖/无额外内容/唯一候选、没有差异，且仍选择本地第一候选、本地颜色与内容证据不冲突，服务端才可能条件自动通过。模型自报置信度不参与放行。改选候选、证据缺失或任何冲突均交给员工。

摘要分别显示本机自动、AI 条件通过与员工确认。接口的 `stats.auto` 包含前两者，`stats.ai_auto` 是其中 AI 条件通过的子集，不能相加重复统计，也不能把自动结果称为人工确认。

## AI 评估与资格激活

开发者先用合成图验证接口、错误降级与反例边界，再用未参与调试的独立业务留出批次验证。标签应在查看模型输出前独立冻结，不能使用模型自己的判断作为答案；所有计划案例及失败都要保留。现有 60 张业务回归映射只用于历史回归，不能充当新的独立业务验证。

以下命令使用本机已经保存的设置，不接受命令行密钥。准备合成图和标签，不调用 API：

```powershell
.\.venv\Scripts\python.exe tools\run_ai_evaluation.py --synthetic --out tmp\deepseek_prepare_01 --settings-dir "$env:LOCALAPPDATA\HSD图片编号工具" --prepare-only
```

真实合成评估使用另一个空目录并去掉 `--prepare-only`；会发送生成的测试预览并产生费用。程序输出标签、完整调用记录和摘要，**不会激活业务自动通过**。合成测试结果仅证明该批测试的表现，不代表真实业务准确率。

```powershell
.\.venv\Scripts\python.exe tools\run_ai_evaluation.py --synthetic --out tmp\deepseek_live_01 --settings-dir "$env:LOCALAPPDATA\HSD图片编号工具"
```

对独立人工标签与真实调用记录进行本机验证，不再调用 API：

```powershell
.\.venv\Scripts\python.exe tools\validate_ai_review.py --labels tmp\business_holdout\labels.json --observations tmp\business_holdout\observations.json --output tmp\business_holdout\validation-report.json
```

每个可激活类别必须有至少两个独立留出批次，包含人工独立核验的真实业务批次；每批均有正例、反例/不确定例和实际通过的正确正例。合计至少两个有效正例、五个反例，覆盖颜色变化、局部替换、额外内容、局部相同和近重复五类，并且全部记录中零错误自动通过。脚本会验证真实调用、实际模型、案例与图片/候选/源文件指纹，拒绝遗漏失败、重复分组或混用模型的记录。

审核达标报告后，给同一验证命令显式添加 `--activate --data-dir "$env:LOCALAPPDATA\HSD图片编号工具"`，才会在指定工具数据目录签名保存资格。仅 `synthetic_known_truth` 合成标签或 `reference_map` 历史映射不能激活；不得改写来源标签绕过要求。资格仅覆盖通过的模型和类别，**7 天后到期**；提示词/协议或相关复核实现变化后失效，实际模型不匹配时不放行。失效后回到评估建议与人工确认。具体数据契约见 [CONTRACTS.md](CONTRACTS.md)。

## 开发验证

v1.2.0 本轮实测：263 项自动测试通过；最终 Windows 便携程序启动、依赖与源码/冻结实现指纹自检通过，60 张回归和无损导出校验通过。正式基线与升级后均为 **44 自动 / 16 人工，AI 新增自动 0**。16 项真实 DeepSeek 请求全部成功，模型判断相同 1、不确定 2、不同 13；这些意见不是独立核验答案。本轮没有减少必须人工判断的图片数量，业务自动通过资格未激活。

便携版本轮导入 9.701 秒、本机匹配 228.465 秒、AI 复核 122.908 秒，总自动处理 361.081 秒，导出 9.971 秒；运行期间另有自动测试，不能用于宣称性能提升。员工真实审核耗时未测。本批已知用量按峰值估算 US$0.0215811，非账单。便携导出验收单独清空表格副本的两个编号格，并人工确认一项来验证新增编号，不计为自动通过提升。原始输入、导出 AI 原稿、两格编号和其他工作簿字节均独立核验。

浏览器已跑通可靠批次直达摘要、歧义确认、跳过、撤销和部分导出。随后更新了面板布局与仅剩无法处理项时的摘要跳转；最后一次布局尺寸复测因浏览器控制连接超时未完成，不能将最终按钮位置称为已实测。现有 60 张的参考映射不代表独立业务准确率，未使用留待后续验证的 10.12 批次。

自动测试覆盖编号边界、重复归属、恶意/异常路径、源文件变化、无损导出、WPS 图像保留、图像匹配、长条与重复纹样、缩放与画板留白、局部改动与颜色改动等场景。真实样本是用户提供的测试资料，不放入发布包。

v1.1.1 本机验收：自动测试 69 项通过、1 项跳过（缺业务样本）；合成场景 11 项正例全部自动通过、3 项易混淆反例全部转人工；端到端（合成样本）跑通导入 → 自动匹配 → 摘要 → 导出。

v1.2.0 真实 DeepSeek API 合成评估（2026-10-15，两个不同种子批次，共 14 例）：4 个正例中，3 例给出明确 `same`，1 例为 `uncertain`；10 个反例中，严格 `same` 为 0。“严格 same”要求候选有效、五项核验均为 true 且无差异，不能只看一个相同标签。这是已知真值合成图的有限测试；本轮没有生产自动放行，不构成独立人工业务验证资格，也不据此推算真实业务准确率或审核数量下降。

## 本机数据

设置、加密密钥、用量、验证资格、日志、临时图片和 AI 提取文件保存在 `%LOCALAPPDATA%/HSD图片编号工具`。任务在本次进程内管理，刷新页面可以恢复当前任务；退出程序后不恢复未导出的任务。最终结果写到用户指定位置，临时缓存清理不涉及导出的结果。仍不包含员工账号、统一号码库或后台收件功能。业务预览、调用记录、验证标签、密钥与资格文件不进入 Git 或发布包。
