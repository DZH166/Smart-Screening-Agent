#  HSD 图号助手

图片与 AI 设计文件对应编号工具，支持 Windows 本机、局域网共享，以及独立启用的 Linux HTTPS 员工服务。用户确认的范围：固定 XLSX 模板 A 列编号/B 列图片；HSD + 四位新流水号；保留已有编号；只对成功匹配的空白编号行填号；疑难项人工复核；非破坏性输出副本。

管理员从“Key 账本 → 员工访问码 · 登录管理”进入访问码页面，可增加、停用或删除多个访问码。原有配置码继续有效；所有已启用的码都可登录员工入口，不能进入管理员分区，也不会共享不同浏览器的任务。新增码保存后不回显，重启后保留；停用只影响后续登录，已经登录的会话按原规则到期。功能已整合至v1.15.0，说明见 [访问码功能验证](docs/admin-access-codes-verification.md)。

当前源码版本：`v1.19.2`（2026-10-27；GitHub 发布资料于 2026-10-28 对齐）。素材生成后可直接下载，支持单张一次高清精修、精修前后对比和舍弃恢复；自动识别按候选分别检查，符合条件的定位失败自动重试一次，失败原图可一键重试。见[本版记录](docs/material-v1.19.2-verification.md)及[版本发布](https://github.com/DZH166/Smart-Screening-Agent/releases/tag/v1.19.2)。

流程为“导入 → 自动查找与核验 → 仅处理剩余疑难项 → 摘要确认并导出”。主机已启用 AI 且有可用 Key 时，DeepSeek 从完整的安全预览库查找对应图片，**同时由本机独立匹配并核验**；AI 关闭或无可用 Key 时沿用完整本机流程。可靠匹配由服务端按本机证据直接通过，不要求员工逐张查看；没有疑问项时直接进入摘要。**模型的相同建议不等于自动通过**，发布包不预置 AI 业务自动通过资格。v1.6.0 起不设表格、ZIP、HTTP 上传、单个 AI 与展开总量的固定字节上限及压缩比限制；实际容量仍受磁盘、内存和网络影响，保留文件数量、图像像素及归档有效性检查。

## 素材提取

员工选择或拖入PNG/JPG/WebP，开始提取后查看实时阶段、累计用时和已处理数量。每张原图仍先由Seedream清理、DeepSeek定位，再由Seedream逐个提取；密集设计使用放大局部参考，长条比例不合适时回退完整原图。保留完整输出画布和透明通道，不本地裁边、删白色内容或放大4096；仍最多8路、32MP参考预算。

结果卡片直接提供“下载、精修、舍弃”。生成结果无需先确认即可下载单张PNG或全部未舍弃素材ZIP。可下载只表示文件可获取，不代表已人工审核或画质合格；下载不写确认记录。舍弃只隐藏当前结果、不物理删除，可在“已舍弃”中恢复。图号助手原有审核及导出流程不变。

“精修”仅将当前这一张结果再交给已配置的Seedream一次，要求保持构图、人物、文字、配色和完整设计，提升清晰度和细腻程度，不加描边。精修不再清理整图、不调用DeepSeek定位，不自动重试或追加精修；默认提取也不自动精修。透明输入保留透明背景，不透明输入保持原背景。模型仍可能改变细节，不能保证恢复原图没有的内容。

成功后用新结果替换当前卡片，保持原位置并标记“已精修”；点击图片查看精修前后对比。保留直接前一版供对比，上传原图始终保留。精修失败、停止或提交异常保留旧结果供下载；计费状态未知时不盲重发，再次精修需明确确认。三天保留及任务归属、源图/输出完整性检查保持。

识别时一个不可用范围不会使其他可用范围全部失败；跳过数量在批次记录中说明。只有已确认返回、但定位判定失败时才自动再识别一次，第二次去掉坐标尺参考；未知计费不自动重发。失败原图的“自动重试”会重新执行这张原图的清理、识别与生成，可能再次产生调用费用。精修过程中保留结果列表与图片对照；当前服务端仍在本批忙碌时暂停下载，完成后恢复。

列表使用640px轻量预览，放大和下载使用完整PNG，局部操作保留已有图片节点。常规说明默认折叠，真实问题仍可见；其他设计的失败记录集中在“本批记录与问题”。详情提示：“如需再次优化，可选择精修，或自行使用 GPT 图像模型处理。”这是员工自行处理建议，不会自动上传到GPT。

每批累计用时不因切换图片或阶段重置；已知本张设计总数时显示真实处理比例，不伪造模型内部进度。漏提取仍可从原图框选补提。Key由管理员在“Key账本”配置，员工无需配置；服务器暂存三天，员工下载到自己电脑，不使用OSS。

**效果边界：** 所有生成及精修结果仍未取得独立画质资格。可直接下载不等于自动核验、生产合格或文字配色完全一致。本轮使用合成样例及模拟接口验证功能，不追加付费模型调用；真实效果由员工自测。

## v1.12.0 Linux 云服务器网页

本节记录云服务的运行方式和隔离配置；证书、原站健康、真实上传下载、关闭与最终测试结果以 [v1.12.0 云部署记录](docs/cloud-v1.12.0-verification.md) 中的实际验收为准。

员工打开 HTTPS 页面，输入管理员分发的员工访问码，上传自己电脑的 `.xlsx` 和 AI `.zip`，确认本批起始号；系统自动处理后只审核疑难项，确认摘要并下载 ZIP 到自己的电脑。原电脑文件保留，服务器不接 OSS，也不会把员工上传的原始文档发送给 DeepSeek。管理员统一管理云实例的 Key，员工不需要填写。

服务器会暂存每批上传、预览和输出。仅云模式在处理进入可审核、完成或失败状态后保留三天；成功编辑、换候选或再次处理会刷新保留期。清理器约每分钟检查，只清本服务有签名登记、归属和路径验证通过的 `uploads/`、`employee_outputs/`、`jobs/` 与 `task_records/` 对应批次；素材提取使用独立的 `material_tasks/` 签名记录及同样的三天保留和活动保护。运行、排队、操作、预览或下载期间不清。下载完成不等于浏览器已落盘，不触发立即删除。签名异常、链接或无法确认归属的目录保守保留；停机时不运行清理，崩溃遗留运行任务在重启后重新开始保留期。清理不触及 Key、累计用量和 Windows/LAN 历史记录。

云入口与 Windows/LAN 入口分开。`python -m hsd_tool.cloud_server` 使用 Python 3.12 和单个 Gunicorn worker，不能用增加 worker、重载或多实例共享目录扩容。正常 TERM 收敛 HTTP 与已接受的后台工作并保存任务。云模式同版本重启后，持有原浏览器私有恢复 Cookie 的员工须重新输入访问码，才可恢复保留期内本人任务；中断任务明确报错，不自动重跑 AI。已完成结果仍经过输入/输出校验再下载。换浏览器、丢失 Cookie、超过三天或版本/实现改变不提供旧批次恢复；升级前请完成并下载。登录会话本身仍最长八小时且重启失效。

部署配置示例在 [`deploy/cloud.env.example`](deploy/cloud.env.example)、[`systemd 服务`](deploy/hsd-agent.service.example)、[`专属挂载`](deploy/hsd-storage.mount.example) 和 [`Nginx 站点`](deploy/nginx-hsd.conf.example)。这些模板不能直接覆盖原站配置；实际域名/IP、证书与端口需先核对。云入口只接收来自 loopback 代理、匹配公开 Host 和 HTTPS 协议的请求，代理必须覆盖客户端地址头。代理连接不提供主机权限，云端禁止文件选择、任意主机路径导入、打开结果目录、退出工具和旧主机设置接口。

| 配置 | 用途 |
| --- | --- |
| `HSD_PUBLIC_ORIGIN` | 精确 HTTPS 源地址，本次目标 `https://39.106.45.116:8443` |
| `HSD_BIND_PORT` | 仅监听 loopback 的后台端口，默认 `8830` |
| `HSD_DATA_DIR` | 专属挂载卷中的上传、缓存、结果和私有记录目录 |
| `HSD_SETTINGS_DIR` | 服务私有的加密设置与累计用量目录 |
| `HSD_CREDENTIAL_KEY_FILE` | 与设置目录分开的 32 字节 AES-256-GCM 机器私钥文件路径 |
| `HSD_EMPLOYEE_CODE_FILE` | 员工访问码文件路径，默认至少 16 位；不沿用公开的 LAN 默认码 |
| `HSD_EMPLOYEE_CODE_MIN_LENGTH` | 可选实例设置，默认 16；1–64 的整数，仅用于管理员明确选定的访问码 |
| `HSD_ADMIN_CREDENTIAL_FILE` | 独立云管理员账号与 PBKDF2 密码哈希文件路径；没有内置默认云口令 |

环境文件只写地址、路径和非敏感的实例长度设置，不写 API Key、密码或访问码。显式长度设置只影响当前实例，不改变可见字符检查、登录限流或管理权限。私钥和凭据文件由部署时创建，目录/文件归属服务用户、权限为 `0700/0600`；Linux 供应商 Key 用 AES-256-GCM 加密，不回退明文或仅会话保存。Windows 仍使用 DPAPI，原 Windows 密文不能直接复制到 Linux。只有已登录管理员可配置Key、使用DeepSeek账本或单独的火山方舟查看接口；员工和普通配置接口不返回密钥。新云主机不带 AI 业务自动通过资格，迁移部署不会扩大模型发送范围或放行条件。

同机原站 80/443、应用和数据库保持，新增独立用户、目录、Python 环境、systemd 服务及 HTTPS 8443 站点。已选资源隔离配置为：预分配 **12 GiB** 的独立 ext4 数据卷、CPU 配额 **1 核**、内存上限 **2 GiB**；挂载失败禁止服务回退写根盘。文件不设固定字节上限，但超过卷可用空间或内存能力仍会失败；这些配置不构成任意批次容量或速度承诺。Nginx 不缓存私有结果，关闭请求体缓冲，必要请求体临时文件落本项目卷中。

当前选择同 IP 不同端口，浏览器 Cookie 不按端口隔离；随机名称、HTTPS、HttpOnly、Origin 校验和服务端权限不等于完全 Cookie 隔离。用户已知此边界，后续应改独立域名。不要为本项目修改原站业务配置、数据库或对外入口。

## v1.9.0 AI 查找与本机核验

启用主机现有 AI 开关即可采用新流程，员工无需额外选择模式或重新填写 Key。AI 请求保留全部符合条件的单画板候选预览，查询图片按组发送；长条图保留完整概览和覆盖全图的顺序分段。库过大而不能完整发送时，不截掉候选制造唯一答案，而是保留原因并由本机继续处理。文件名、目录顺序、行号和样本答案均不作为检索或通过依据。

本机独立验证不以 AI 建议缩小候选库，也不把模型的 `same` 变成本机强证据。图案、颜色、完整内容、竞争与文件归属仍按原条件验证；AI 与当前候选不一致时明确提示。模型失败、限流或无有效建议时，只保留有效的本机结果；本机核验失败或任何输入发生变化时不能用 AI 建议导出。并行阶段分别显示 AI 组数和本机图片数量，不合成为整批百分比；两路结束、重新校验后才公布最终结果。

剩余疑难项仍可按需补跑原有二次复核，资格及放行规则不变；全库查找与二次复核的用量分别展示。两种模型意见都不取代原文件、已有编号和导出校验。当前资格签名绑定 13 个模块，含 `ai_first`、`appearance_cache` 与 `cancellation`；旧资格不能沿用，也不据现有 60 图回归或合成控制声明通用准确率。10.12 批次留待后续，不用于本版验收。

本版真实执行结果、失败与验证边界见 [v1.9.0 验收记录](docs/ai-first-v1.9.0-verification.md)。此前实验中的模型检索时间不等于本版整批耗时，不把阶段相加或并行时间混报为员工整体提速。

## v1.8.0 处理与下载

以下保留 v1.8.0 的历史实现和验收事实；当前流程以本页 v1.9.0 说明为准。

本版复用同一匹配任务中已按像素内容摘要、尺寸和处理参数绑定的尺度图、内容边界、颜色统计及粗搜索结果，减少精细验证的重复计算。临时复用数据有独立的实现版本与内存预算，任务结束即释放；不按文件名、大小或修改时间认定相同，也不跨任务复用旧 AI 意见。像素算术减少临时数组，只在已有条件足以否定候选时跳过不影响结论的昂贵计算；颜色、局部差异、完整覆盖、竞争判断与通过门槛保持。

CPU 匹配、AI 等待和导出使用独立调度：CPU 1 个 worker、AI 批次协调 2 个、全局 AI 案例 2 个、导出 1 个。只有候选集合不重叠的独立案例才并发，结果按稳定案例顺序校验和写回。Key 数量不增加并发额度；429 触发全池 60 秒冷却，已启动请求等待收敛，未启动的案例保留明确记录。本地可靠批次或 AI 关闭时不排在其他批次的模型等待之后。

下载 ZIP 和结果文件夹只包含“已编号AI”及唯一一份编号 Excel。对应关系、待处理清单、匹配依据、AI 计划与每次成功/失败尝试移入主机私有 `task_records/<任务ID>/`；正常退出清理临时缓存后仍保留，既不加入员工下载包，也不提供跨员工读取入口。未处理和跳过数量继续在摘要显示，表格原行保持原状；部分导出、摘要确认、源文件和完整性复验不变。

实测耗时、首次/重复处理口径、合成 AI 等待与验证限制见 [v1.8.0 性能验收记录](docs/performance-v1.8.0-verification.md)。实际 DeepSeek 等待与网络传输不能用合成延迟替代；本版没有调整模型、价格估算或图片发送范围。匹配与复核实现变化使旧资格按原规则失效，保留原有加密 Key 和设置。

## 员工界面

- 左侧「功能」栏固定列出全部功能：图号助手、素材提取；点击在同一页面切换并保留各自任务，窄屏自动变为横向标签。素材提取原顶部入口已移入侧栏。

- 上传显示实际上传进度，后台显示当前阶段及该阶段进度；排队显示位置，不把单阶段百分比当作整批百分比。
- 有疑问时默认只列出需要处理的项目，状态行突出剩余数量。主区域用于图片对照和确认、换候选、跳过；长条图上下排列，可放大。全部结果、已完成及已跳过可按需查看。
- 图号疑难项可打开“批量确认”，对照当前筛选中可处理的图片与候选，明确勾选后一次提交。默认不勾选；缺图、损坏、多画板、重复预览、文件或编号冲突仍需单独处理。整组成功才记为人工确认，整组可撤销，不改变自动通过条件。
- AI 建议保留“需人工确认”标记；具体差异、文件异常及复核对象与当前选择不同的提示保持可见，完整复核说明与技术依据展开查看。
- 摘要默认显示可导出、新增编号、未处理/跳过和结果获取方式，点击“确认并导出”即可；未完成行保持原状。通过方式分类和本批 AI 用量位于“处理详情”。完成页突出下载/打开结果和处理下一批。
- 主机管理员从右上角“主机管理”进入独立“管理员分区 · DeepSeek”，管理 AI 开关和多个 Key；管理员页不再展示费用统计和实时调试；共享地址、访问码及退出工具仍在主机管理。员工端无这些管理权限，服务端同样拦截。

Linux 服务使用上方独立云入口；下面保留远端 v1.11.0 的 Windows 源码运行与便携构建/验收命令模板，不表示本轮已构建或验证该 Windows 发布包。使用 Python 3.12；在项目目录执行：

## 管理员分区：AI 开关与 API Key

打开 `/admin` 登录，或由主机从“主机管理”进入。左侧导航只有三项：Key 账本（DeepSeek、火山方舟、员工访问码配置及 Key 查看）、功能区（图号助手与素材提取入口）、帮助。DeepSeek 配置只有一份，图号助手与素材提取共用，改一次两边同时生效；素材清理的火山方舟配置从“Key 账本”进入独立页面 `/admin/material`；“功能区”素材入口直接进入使用界面。

批量输入每行一个 Key，最多100个，默认遮罩，可点击“显示/隐藏”核对，提交前立即清空；原有 Key 保留。支持标签、启停和删除，普通列表不回显 Key 或尾号；账本的显式例外见下文。保存成功不代表接口验证成功。Windows 逐 Key 用当前用户 DPAPI 加密；环境变量 Key 只能启停。处理中的任务仍禁止修改配置，其他页面先改会返回409，必须点击“刷新设置”核对，不能静默覆盖。

页面每30秒仅请求 Key 设置/状态，隐藏或离开后停止，返回时读取最新状态；不再请求调试与累计费用接口。后台刷新不禁用正在输入的控件，也不替换标签输入和删除确认；遇到配置冲突保留编辑现场，等待显式刷新。

每次新的 AI 请求从当前可用的 Key 中等概率随机选择，所有员工共用；不按添加顺序轮流，也不固定分配给某位员工。连续请求可以选中同一个 Key，短时间内不保证每个 Key 使用次数相等；停用、暂停、冷却或本次重试已排除的 Key 不参与选择。

认证/余额异常会暂停 Key，修复后可先停用再启用；网络/服务故障按原 Key 重试，每组/案例总尝试最多2次。429继续触发全池60秒冷却，多 Key 不扩大官方额度，也不增加现有并发量。后台累计用量、脱敏诊断及任务私有完整记录仍保留，模型请求、匹配和导出规则均未改变。Key 分配实现纳入原有资格签名，切换实现后旧 AI 条件自动通过资格失效，须按原流程重新验证；不会自动激活。

进入 `/admin` 先要用管理员账号登录。Windows/LAN 沿用原管理员账号；云实例使用部署时私有凭据文件里的独立账号与密码哈希，不提供内置默认云口令。密码由管理员保管，仓库、文档和发布包都不记录明文。未登录时 `/admin` 只显示登录表单，`/api/admin/*` 返回 401；登录会话最长 8 小时，服务重启后失效；同一地址 60 秒内连续 10 次失败会被暂时拒绝。页面右上角有“退出登录”。

管理员可以在**局域网内其他电脑**打开同一批设置：主机以 `--lan` 启动并保持运行，其他电脑浏览器访问 `http://主机IP:端口/admin`，输入账号密码即可看到同一批 Key、标签和开关，不需要员工访问码。管理员数据始终保存在那台主机上，请统一使用主机地址，不要打开各台电脑本机的 `/admin`（那是本机独立的数据）。主机专属操作——选择文件、打开结果目录、退出工具——仍只允许在主机本机执行。管理员页面与登录走明文 HTTP，只应在可信内网使用。

页面底部“查看或复制 Key”默认收起，展开才从 `/api/admin/ledger` 获取明文与标签；默认遮罩，可显示或复制。收起、退出、登录失效和离开页面均销毁账本内容；退出失败不会显示为成功退出。账本受登录会话限制、响应 `no-store`、不写日志；**显示后的截图、录屏或旁观仍会暴露密钥**。火山方舟Key使用独立的按需查看/复制入口，不混入此账本；其他普通接口及员工端不回显Key。

Windows v1.10.1 历史验证见 [同步上线记录](docs/deployment-v1.10.1-verification.md)；历史界面验证见 [v1.9.1 管理页验收记录](docs/admin-v1.9.1-verification.md)。这些记录不代替本次 Linux 云服务的上线验收。

## DeepSeek 设置与数据范围

1. 由主机管理员展开右上角“主机管理”，进入“管理员分区 · DeepSeek”，批量添加Key并保存 AI 开关；员工浏览器沿用主机设置，不需要填写。
2. 普通 Key 列表仅显示标签和状态；已登录管理员的独立账本允许显示和复制密钥。批量输入在提交前清空，清空输入不删除已有 Key。Windows 使用当前用户 DPAPI 加密保存，不写入日志、导出结果或 Git；保存成功不表示接口已验证可用。
3. 导入后自动进行全库 AI 查找与本机独立核验；没有可用 Key 或开关关闭时执行完整本机匹配。资格提示仅约束模型意见能否条件通过，不影响本机证据完整的直接通过。
4. 只处理剩余疑难项，查看查找建议、当前候选与本机原因，再确认或跳过；如页面提供“对此批运行 AI 复核”，可以按需补跑原二次复核。两种用量分开。请求失败、额度不足、限流、网络异常或响应无效不抹掉有效本机结果，也不把模型建议当作已确认。

模型固定为 `deepseek-flash`，仅由运行工具的主机后端调用 DeepSeek。全库查找发送可处理的表格图片、全部安全单画板候选预览、完整概览和覆盖全图的长条顺序分段，使用每次任务随机映射并独立打乱的匿名 ID；查询分组不删减候选库，不提供文件名、行号或旧匹配答案。按需二次复核继续发送真实可信竞争候选，有可验证几何时附同尺度对照与覆盖位置图；该旧复核路径超过五个可信竞争候选仍交人工。**原始 XLSX、ZIP、AI 文件以及本机文件路径不发送给 DeepSeek**；局域网上传到主机是另一条数据路径。图片中本来包含的文字仍属于图片内容，会随预览发送并被当作数据而非指令。

重复预览、文件归属或编号冲突、损坏/无法读取的预览、多画板等硬异常不能交模型解除；不安全的候选不进入全库查找。无可信候选、关键细节不清楚、本地颜色/内容矛盾或模型改选不能凭 AI 意见放行。独立本机核验支持的另一候选仍以其自身证据决定状态，并明确展示与 AI 的不一致。源文件或比较图片变化使旧结果无效，须重新导入。关闭 AI 后继续使用纯本机流程。开发者可通过 `DEEPSEEK_API_KEY` 环境变量提供密钥，本机保存的密钥优先；清除本机密钥不会删除环境变量。

管理员分区已移除费用估算界面，后台继续保留累计账本；员工的“处理详情”仍只显示本批用量。按已知 token 用量和程序记录的峰值单价，以 USD 保守估算，**不是账单，实际费用以 DeepSeek 账单为准**。请求用量未知时会单独提示次数，费用统计不完整，不将未知费用记作零。本版不设置费用上限或达到某金额后自动停止的开关。

价格依据于 2026-10-15 核对的 [DeepSeek 官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)：`deepseek-flash` 峰值价格为每百万输入 token 缓存命中 US$0.006、缓存未命中 US$0.30，每百万输出 token US$1.20。本工具统一用峰值单价估算，不推测实际调用时段折扣；价格可能调整，估算不替代账单。

## 模块

- `workbook.py`：流式读取 WPS 图片与行号，ZIP/XML 定点更新空白编号，不经普通表格引擎重保存。
- `matching.py` / `matching_verification.py`：安全读取 AI 文件夹/ZIP，渲染预览；通过几何、像素、颜色、实测周期及完整内容覆盖等证据核验，记录两条通道各自的依据。
- `ai_policy.py` / `ai_images.py` / `ai_client.py`：复核资格、预览与完整分段、后台 DeepSeek 请求及结构化响应校验。
- `ai_first.py`：匿名全库预览检索、严格解析候选建议及独立用量/完整尝试记录，不改变匹配或编号状态。
- `ai_settings.py` / `ai_usage.py` / `ai_registry.py` / `ai_workflow.py`：加密设置、用量记录、限定场景验证资格与后台任务。
- `service.py`：任务状态、编号规划、人工确认、文件校验、事务式导出。
- `server.py` / `uploads.py`：本机/受限局域网接口、员工上传与任务归属、结果下载、主机原生文件选择窗口。
- `gateway.py`：内网 AI 网关，持有唯一一份 Key，校验客户端令牌后转发查找与复核请求。
- `admin_auth.py`：管理员分区的账号口令校验、会话有效期与登录限速。
- `static/`：中文导入、复核、导出界面。

编号与文件名冲突采用保守处理，不覆盖原件。新编号只规避当前表格中的已用号；跨批次起始号由员工确认。缺图和跳过行不会分配新号。输出保留完整工作簿，其余 XLSX 内部部件原字节复制。

## 匹配与自动通过

历史 v1.3.0 从正式 `v1.2.0` 的 44 自动 / 16 人工基线实施通用优化，未混入本机另一份未发布的 47 自动 / 13 人工开发稿。当前仍不使用文件名、行号、目录顺序或旧核验答案作为生产依据。

自动通过不是单一分数阈值，而是多证据交叉验证的结果：

- 几何通道：保留特征点、仿射与内部像素检查；对插值保护区排除的薄边缘，独立验证两侧真实像素后才计入覆盖。
- 纹样通道：先粗筛，再用较高分辨率和细尺度/相位检查。像素误差、变化面积、最差区域、颜色及完整原稿覆盖必须一起通过，不直接降低门槛。
- 完整内容：匹配的局部不能代表整份原稿。只有实测成立的周期才能解释重复区域，新增图案、颜色或实心局部差异仍阻断通过。
- 唯一性与归属：完整比较所有原稿，真正接近的竞争候选保留人工；仅共享局部图案的弱候选不抢占可靠对应，也不按排除法分配剩余文件。

阈值由像素误差的物理含义与正例、易混淆反例的实测间隔确定，不针对某批样本调参，也不使用文件名、行号或样本答案作为匹配依据。

AI 的“相同”意见不等于通过。全库查找协议只返回候选建议，不提供自动通过资格；本版自动通过来自独立本机核验。按需二次复核仍使用 v2 逐候选协议，要求每个候选独立回答，当前候选的差异不能写成其他候选的差异；漏项、虚构候选、检查项与结论矛盾都不放行。只有相应场景取得有效独立业务资格且全部条件通过时，该旧复核路径才可能条件自动通过。本版不预置、不新增激活；签名现绑定 13 个模块，旧实现资格失效。模型自报置信度不参与放行，不能用改选建议补齐缺失证据或解除冲突。

摘要的“处理详情”分别显示本机自动、AI 条件通过与员工确认。接口的 `stats.auto` 包含前两者，`stats.ai_auto` 是其中 AI 条件通过的子集，不能相加重复统计，也不能把自动结果称为人工确认。

## AI 评估与资格激活

开发者先用合成图验证接口、错误降级与反例边界，再用未参与调试的独立业务留出批次验证。标签应在查看模型输出前独立冻结，不能使用模型自己的判断作为答案；所有计划案例及失败都要保留。现有 60 张业务回归映射只用于历史回归，不能充当新的独立业务验证。

以下命令使用本机已经保存的设置，不接受命令行密钥。准备合成图和标签，不调用 API：

```powershell
.\.venv\Scripts\python.exe tools\run_ai_evaluation.py --synthetic --out tmp\deepseek_prepare_01 --settings-dir "$env:LOCALAPPDATA\HSD图片编号工具" --prepare-only
```

真实合成评估使用另一个空目录并去掉 `--prepare-only`；会发送生成的测试预览并产生费用。程序输出标签、完整调用记录和摘要，**不会激活业务自动通过**。合成测试结果仅证明该批测试的表现，不代表真实业务准确率。

```powershell
.\.venv\Scripts\python.exe tools\run_ai_evaluation.py --synthetic --out tmp\deepseek_live_01 --settings-dir "$env:LOCALAPPDATA\HSD图片编号工具"
```

对独立人工标签与真实调用记录进行本机验证，不再调用 API：

```powershell
.\.venv\Scripts\python.exe tools\validate_ai_review.py --labels tmp\business_holdout\labels.json --observations tmp\business_holdout\observations.json --output tmp\business_holdout\validation-report.json
```

每个可激活类别必须有至少两个独立留出批次，包含人工独立核验的真实业务批次；每批均有正例、反例/不确定例和实际通过的正确正例。合计至少两个有效正例、五个反例，覆盖颜色变化、局部替换、额外内容、局部相同和近重复五类，并且全部记录中零错误自动通过。脚本会验证真实调用、实际模型、案例与图片/候选/源文件指纹，拒绝遗漏失败、重复分组或混用模型的记录。

审核达标报告后，给同一验证命令显式添加 `--activate --data-dir "$env:LOCALAPPDATA\HSD图片编号工具"`，才会在指定工具数据目录签名保存资格。仅 `synthetic_known_truth` 合成标签或 `reference_map` 历史映射不能激活；不得改写来源标签绕过要求。资格仅覆盖通过的模型和类别，**7 天后到期**；提示词/协议或相关复核实现变化后失效，实际模型不匹配时不放行。失效后回到评估建议与人工确认。具体数据契约见 [CONTRACTS.md](CONTRACTS.md)。

## 本机数据

以下恢复限制适用于 Windows/LAN；Linux 云模式以本页上文的 v1.13.0 私有恢复策略为准。默认本机设置、加密密钥、用量、验证资格、日志、临时图片和 AI 提取文件保存在 `%LOCALAPPDATA%/HSD图片编号工具`。员工服务使用独立 `--data-dir` 保存上传副本、任务与结果，`--settings-dir` 复用主机的 AI 设置、用量及资格。`jobs` 中的临时匹配素材可清理，`task_records` 中的私有对应关系、待处理清单、匹配依据及 AI 尝试记录在正常退出后保留；这些文件不加入下载包或发布包，也不等于任务可以恢复。任务仅在本次进程内管理，同一有效浏览器会话刷新可恢复自己的任务；更换浏览器、重新登录或服务退出后无法找回任务下载入口。请及时下载并妥善保存结果；主机上的上传副本和结果由管理员另行管理，不能将任务缓存清理理解为上传原稿已全部删除。本机路径模式仍输出到员工指定位置，原件不改。仍不包含员工账号、统一号码库或后台收件功能。业务预览、调用记录、验证标签、密钥与资格文件不进入 Git 或发布包。
